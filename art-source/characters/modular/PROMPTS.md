# 三职业分层角色素材记录

## 生产模式

- 工具：Codex 内置 ImageGen。
- 模式：底模使用 `identity-preserve`，装备层使用 `stylized-concept / compositing`。
- 透明流程：纯 `#00ff00` 绿幕 → 官方 `remove_chroma_key.py`（`auto-key border`、`soft-matte`、`despill`）→ Sharp 对齐与压缩。
- 运行时规格：所有底模和装备层均为 640×960 RGBA，四角透明。
- 图层顺序：`base → body → head → weapon`。

## 底模提示词模板

以职业原始待机立绘为身份参考，保持成年（18+）身份、脸部、瞳色、发色、
发型和日系手游渲染风格。生成完整全身、正面略朝右的统一纸娃娃姿态：
双脚稳定，右手在腰侧留出空握柄，左手展开用于施法。移除武器、头饰、
披风、宽袖外袍和外层裙甲，只保留端庄的海军蓝 / 白 / 樱粉训练内搭与短靴。
严格 2:3 画布、纯 `#00ff00`、无阴影、无文字、无额外物体。

职业身份锚点：

- 剑姬：银紫高马尾、蓝眼。
- 魔女：粉色短发、蓝眼。
- 灵巫：紫蓝长发、紫眼。

## 装备层提示词模板

同时引用已生成的职业底模和对应 `public/assets/equipment/<region>/<slot>.png`
图标，只输出一个装备层。保持相同画布、人物比例和身体锚点；禁止输出人物、
皮肤、脸、头发、手、腿、人体模型、其他装备、阴影和文字。

- `body`：只输出空心、无袖、贴合底模体型的外层衣装，手臂完整露出。
- `head`：只输出对齐发际线的花冠或草帽。
- `weapon`：只输出完整武器道具，握柄对齐右手；若生成了手臂或手，重试为纯道具。
- R1：樱枝短剑、樱花冠、蓝白樱粉战裙。
- R2：棉花糖锤、蜂翼稻草帽、蜂蜜海军蓝围裙裙装。

## 校准记录

- 剑姬原始 alpha 母版保存在 `swordsman/alpha-unscaled/`，
  `scripts/align-swordsman-layers.mjs` 负责缩放、翻转 R2 武器并写入运行时画布。
- 魔女原始对齐母版保存在 `witch/alpha-master/`，
  `scripts/resize-aligned-character-layers.mjs witch` 负责生成 640×960 运行时图。
- 灵巫生成后直接完成 640×960 锚点校准；R1 衣装初稿因商品陈列姿态不合格，
  已重试为无袖贴体版本。R2 草帽曾压眼，已上移并缩小后通过。
- 剑姬 R1 衣装第一稿尺寸过大且有漂浮袖口，已重试为无袖紧凑版本；
  R1 武器第一稿误生成人手，已重试为纯武器道具。

原始 ImageGen 结果仍保留在 Codex 生成目录；仓库只提交不可再生的 alpha 母版、
校准脚本和发布用成品，避免重复保存绿幕副本。
