# 樱酱衣裙图标源板

## 最终有效提示词契约

> 二次元手游装备图标源板，只画服装单品，不画人物、头部、手脚、武器、文字、
> 徽标或边框。服装正面平铺或隐形衣架展示，轮廓完整，柔和赛璐璐与精致布料纹理，
> 清新可爱的蓝白粉基调；每件严格复刻对应樱酱整身资产的衣型、配色与装饰。
> 每格只放一件，主体居中且彼此不接触。纯荧光绿背景（#00ff00），不得使用绿色
> 服装或绿光，便于确定性去背。

生产时按下列格序补充对应主题描述；不得把参考图中的猫耳、头饰、刀鞘带进衣裙：

- `body-icons-batch-1.png`（3×2）：r1、r2、r3、r4、r5、r6 区域衣裙。
- `body-icons-batch-2.png`（3×2，最后一格空）：r7、绯焰套、幽影套、血月套、晴蓝副本。
- `body-icons-batch-3.png`（3×2，最后一格空）：月紫、琥珀、绯樱副本，草莓奶霜、月桂星糖精品。
- `body-icons-batch-4.png`（2×1）：绯樱星愿精品、月蓝巡灯好感振袖。

第一批源板来自游戏资产生产工具的角色一致性工作流；后三批使用内置图像生成模式。
所有源板仅作为生产母版，运行时图标必须由
`scripts/build-appearance-debt-assets.mjs` 去背、逐格裁切并归一为 256×256 RGBA PNG。
`npm run assets:appearance-debt:check` 会从这些源板重建并比较最终像素，禁止手工改成品。
