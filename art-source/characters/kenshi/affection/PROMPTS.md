# 樱酱好感剧情场景原画合同

## 运行时合同

- `story-a/b/c-sheet.png`：每张四格，依次裁出 12 张无人剧情背景。
- `key-cg-sheet.png`：四格纯物件高潮 CG。
- 运行时统一为 `960×640`、无 alpha 的 WebP；确定性裁切命令：
  `node scripts/build-kenshi-story-art.mjs`。
- Galgame 实时立绘位于右侧，因此叙事物件放左 40%，中右 45% 留低细节负空间，
  底部 28% 压低对比给对白框。
- 严禁人物、手脚、动物、人形剪影、人物倒影、可读文字、数字、标志、水印与 UI。
  市场场景必须是无人摊位，远景也不得出现人影。

## `story-a-sheet.png`

四格依次为：

1. 晨光落樱道场：低刀架、榻榻米、训练垫、白蓝刀穗与开向樱庭的障子门。
2. 蓝调雨檐：长凳、干布、闭合蓝伞、湿刀袋、石阶与庭灯。
3. 月光刀鞘：深蓝樱纹刀鞘与尚未系上的蓝白归鞘铃。
4. 夕光磨刀台：磨石、量尺、养护布、护套与带浅缺口的刀锋。

## `story-b-sheet.png`

四格依次为：

1. 深蓝夜巡道场：成排巡灯、合上的巡路板与两枚等大路线标记。
2. 日出迎归门廊：两盏同高、各有独立开关的迎归灯，中央通路完全开放。
3. 晨光礼物低桌：月白磨刀石匣、空白规格卡、空白退换凭据与两只同规格茶杯。
4. 细雨空早市：无人摊位陈列雪白、湖蓝、樱粉刀穗与轻羽织。

## `story-c-sheet.png`

四格依次为：

1. 夕阳巡路图：两条独立彩色路线仅在休息节点相交，旁放空白描图纸。
2. 清晨无人刀穗摊：三色候选刀穗、试系木架与尺寸带。
3. 午后樱川茶席：两只同规格茶杯、小点心与独立安放在矮架上的收鞘太刀。
4. 夜间道场入口：两把独立钥匙、双层刀匣、空白灯牌与并列迎归灯。

## `key-cg-sheet.png`

四格依次为：

1. 月光深蓝樱纹刀鞘、未系蓝白归鞘铃与可解松结。
2. 两盏大小和位置平等、各有独立开关的空白道场灯牌。
3. 双层巡路图、两条独立路线与两枚独立路线标记。
4. 两把钥匙、两个独立锁位的双层刀匣、空白可擦写灯牌与笔。
