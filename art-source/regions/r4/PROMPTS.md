# 区域 4「月下墓园」ImageGen 生产记录

本目录的 47 张有效母版全部由 Codex 内置 ImageGen 独立调用生成，没有复制、改名复用或占位图。统一美术基调为「清新可爱、圆润柔和、月蓝 / 骨白 / 淡薰衣草、珍珠与玻璃高光」；墓园只表现静谧月色与童话式亡灵，不出现血腥、尸体或恐怖脸。

场景母版直接生成不透明画面。怪物、材料与装备均生成在纯色 `#00ff00` 绿幕上，主体禁用绿色，随后使用 imagegen skill 自带的官方脚本抠图：

```powershell
python "C:\Users\Administrator\.codex\skills\.system\imagegen\scripts\remove_chroma_key.py" `
  --input <chroma.png> --out <alpha.png> `
  --auto-key border --soft-matte `
  --transparent-threshold 12 --opaque-threshold 220 `
  --edge-contract 1 --despill --force
```

运行时规格：

- 地图：`768 × 1024 WebP`，不超过 `450 KiB`
- 战场：`1536 × 1024 WebP`，不超过 `520 KiB`
- 怪物：`512 × 512` 透明 WebP，底部锚点 `y=503`，不超过 `120 KiB`
- 材料 / 装备：`256 × 256 RGBA PNG`，不超过 `120 KiB`
