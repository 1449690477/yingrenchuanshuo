## 二、实机发现与修复

### 1. 公会

- 访客入口原先只有蓝粉渐变，接入正式 `guild-home-courtyard.webp` 庭院场景，并保留文字遮罩与减弱动效。
- 公开公会详情的成员行由静态 `div` 改为 52px 可点击按钮，点击后复用统一 `PlayerPeekSheet` 展示职业、等级、战力与立绘。
- 实机发现公会覆盖页跟随“更多”长内容延伸，详情成员行会落到全局底栏下面，点击时误触“副本”。现改为固定在全局顶栏和底栏之间：390 视口实测公会页 `top=58 / bottom=784`，首行中心 `y=566`，底栏从 `y=784` 开始。

### 2. 榜单

- 进度榜主卡接入玩家最深首通所属章节的真实 3:2 战场；新号明确展示第一关场景，未知关卡直接报配置错误，不静默退回占位图。
- 封神榜接入镜界裁决庭场景、封印环、只读公示状态和“当前记录 / 累计判据 / 正常玩家”数据窗；保留原有物理上限说明与公开证据行。
- 场景映射集中在 `src/data/boardVisuals.ts`，并用测试确认首关、内容最深关和镜界资产均真实存在。

### 3. 触控与小屏

- 修复 320 宽挂机体力标题被挤成竖排；实测 `white-space: nowrap`，页面 `scrollWidth === 320`。
- 挂机每日补给、扫荡、最近掉落、全部折叠、掉落分组和掉落行统一提升到 44px 触控基线；320 宽最近掉落显示 5 件，避免横向裁切。
- 自动技能折叠把手、背包评分切换、存档按钮、试炼按钮/次级页签、秘境筛选均提升到 44px。
