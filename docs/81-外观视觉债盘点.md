# 81 · 外观视觉债盘点（2026-08-02）

> 起因：老板连发两张截图报「穿了裙子/鞋子外观没变化」。逐项排查后：
> **两张截图里的渲染其实都符合设计** —— 樱酱的衣裙走整身替换、正确穿上了
> （藏青羽织与格子里的紫裙图标长得不像，被读成"没生效"）；鞋在区域与
> 副本装备下是**刻意**不渲染的（整身装自带靴、独立鞋层悬空错位）。
> 真正的病是 **UI 从不解释 + 若干真实的美术缺口**。本文档是缺口台账。

## 已修（main，2026-08-02）

| 修复 | 内容 |
|---|---|
| 计数器诚实化 | 「x/4 外观部位已变化」的分母是兑现不了的承诺（大多数装备路线永远到不了 4，读起来像有一件坏了）。改为「x 处外观已生效」 |
| 沉默槽点名 | 新增 `silentVisualSlots`：weapon/head/body/shoes 四槽穿了不渲染装备时，界面明示「鞋不改变外观」并附原因提示。首饰四槽不点名（玩家不期待项链上身） |
| 契约测试 | 两条 spec 钉住上述语义 |

## 美术缺口（按玩家可见度排序）

### ① 老四职业竞技场圣痕 · 12 件全无上身美术 —— 建议最高优先
`eq_arena_{swordsman,witch,shaman,catkin}_*` 的 weapon/head/body 全部
slot-only 且盘上无素材；**而樱酱的圣痕三件有美术且正常渲染**。
PvP 最高荣耀装备出现「新角色有、老角色无」的倒挂，最伤老玩家观感。
美术管线可复用 kenshi wearables 那套（授权原画板 → 确定性重建）。

### ② 区域鞋 r1~r7 × 5 职业 = 35 层无美术
区域鞋因此永远不改变外观（现已有 UI 解释兜底，不再像 bug）。
补齐后 `hasVisibleShoes` / `base-noshoes` 管线现成，无代码工作。

### ③ 副本鞋 20 张美术已在盘上、因「悬空错位」被弃用
`assets/characters/modular/dungeon/*/{class}-shoes.png` 全部存在，
但注册被刻意关掉（见 `buildEquipmentDungeonAppearances` 注释）。
若管线能按底图脚位重生成对齐版即可回收 —— 素材成本已经花了。

### ④ 樱酱武器图层锚位悬空
樱酱各武器图层画在腰腹前、不贴手不贴腰（对照：老职业武器锚在垂手位）。
上身读作「刀浮在空中」。需重生成对齐底图手/腰位；数据侧 transform
只有平移缩放、无旋转，治标不治本。

### ⑤ 图标与上身不一致（樱酱区域整身替换）
樱酱的区域衣裙走 `replacementClasses` 整身替换（如 r6 = 藏青羽织袴），
但格子图标是通用裙装图 —— 触发本次误报的直接原因。归 UI 线：
四视觉槽的格子对当前职业显示「实际穿上是什么」的缩略，或樱酱专用图标。
