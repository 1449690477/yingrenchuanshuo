# 14 · 系统清单

> 全部玩法系统的定义、解锁条件、优先级。
> **P0 = 没有它游戏不成立；P1 = 核心留存；P2 = 深度；P3 = 锦上添花**

---

## P0 · 骨架系统（M1–M3 必须完成）

| 系统 | 解锁 | 说明 |
|---|---|---|
| **挂机战斗** | 开局 | 自动战斗、伤害飘字、掉落提示 |
| **离线结算** | 开局 | 打开时弹窗展示离线收益 |

| **背包** | 开局 | 装备/材料/消耗品分页，容量上限 + 扩容 |
| **装备穿戴** | Lv2 | 8 槽，属性对比提示（穿上是变强还是变弱） |
| **关卡推进** | 开局 | 章节选择、通关判定、切换挂机点 |
| **存档** | 开局 | IndexedDB 自动存档 + 手动导出/导入 JSON |

## 界面结构（竖屏底部 5 Tab）

```
┌─────────────────────────┐
│  角色头像 / 等级 / 战力    │  ← 顶部状态栏
├─────────────────────────┤
│                         │
│                         │
│      主内容区            │
│   （当前 Tab 的内容）      │
│                         │
│                         │
├─────────────────────────┤
│ 挂机  背包  养成  副本  更多 │  ← 底部 Tab
└─────────────────────────┘
```

| Tab | 内容 |
|---|---|
| **挂机** | 战斗画面、掉落流水、关卡切换、扫荡入口 |
| **背包** | 装备/材料/消耗品，一键分解、一键穿戴最优 |
| **养成** | 角色属性、装备栏、强化、洗练、技能、宠物、时装 |
| **副本** | 日常本、装备本、无尽塔、世界 BOSS、团本 |
| **更多** | 公会、排行、成就、图鉴、邮件、设置、存档管理 |

## 必须做的「体验兜底」设计

这些不是玩法，但缺了会让玩家很难受，**优先级等同 P1**：

- [x] **一键穿戴最优装备**（按战力自动比较）
- [x] **一键分解**（按品质筛选，可设置保护规则）
- [ ] **一键强化单件 / 全身**（纯逻辑与 store 接口已完成；等待锻造 UI 接入按钮、目标档选择和结果汇总）
- [x] **装备对比提示**（背包里的装备显示相对已穿戴的属性差）
- [ ] **战力变化飘字**（任何操作导致战力变化，屏幕上飘 +XXX）
- [x] **推荐战力警告**（打不过的关卡明确标出来，不让玩家白挂）
- [x] **离线收益弹窗**（打开游戏第一眼看到「你不在的时候赚了多少」）
- [ ] **红点系统**（有可领奖励/可强化/可升级的地方都要有红点）
- [x] **数值缩写**（1.2万 / 3.4亿 / 5.6兆，不要显示 12000000000）
- [x] **存档导出提醒**（单机存档，必须提醒玩家定期备份）
