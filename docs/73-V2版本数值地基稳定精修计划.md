## 零、一句话结论

二版的数值**结构是健康的**（单一权威口径、产出/消耗守恒、等级追内容、门禁体系都在），
但存在 **5 个标尺级失真源**（读 CP 的结论不可信）、**2 个成长曲线问题**、
**2 个战斗/职业问题**、**3 个经济/完成度缺口**。
其中 3 个已在 docs/65、docs/72 登记为「下版本专线」，本次复查**确认它们全部仍然存在**，
并新发现 2 个（PvP 跨职业胜率失衡、珍品商店装备超前污染口径）。

**总原则（手册 §八.1）：数值是算出来的，不是测出来的。先立门禁，再调数。**
本文每个问题都给出：证据 → 根因 → 手册依据 → 处置方案 → 验收门禁。

## 二、五个标尺级失真源（A 类，最高优先级）

> 手册 §一.4：**推荐战力与实际难度必须是同一个式子的两次读数**；
> §八.6：**断言不能自证**。当前所有读 CP 的门禁都建立在这五个失真源之上，
> 所以二版才只能「只报不拦」。这五条不修，后面的调参都是在错误标尺上微调。

### A1 · 威胁轴全程漂移 4.7×：后期怪物打不死玩家

- **证据**（本次 `npm run sim` 实读）：安全边际（玩家能扛几击 ÷ 杀死怪要几击）
  Lv10~19 = 2.63 → Lv30~39 = 3.80 → Lv50~59 = 6.12 → Lv70~79 = **12.21**。
  裸公式外推 Lv120 ≈ 63×。
- **根因**：品质阶梯（common 1.0 → divine 15.0）是乘法跳跃，玩家有效血量在
  65 / 90 / 110 处成倍跳；而 `monsterAtk(level)` 只随等级平滑增长，**没有任何东西跟着抬**。
- **手册依据**：§一.4（同一 f(lvl) 原则）、§六（从体验目标反推怪属性，两轴分开标定：血量管节奏、攻击管生死）。
- **影响**：后期没有死亡威胁 → 防御/生命/减伤/吸血词条贬值 → 只剩「打多久」，
  装备堆肉的玩家感受不到回报（docs/45 承伤模型的效果被半路抵消）。
- **处置（已拍板：按推荐 = 修正③后的方案）**：
  - ❌ 已否方案 1 原形：`monsterAtk` 乘整段 `QUALITY_MUL`（最高 15×）过猛——玩家 EHP
    只吃品质阶梯的 hp/def 份额，不吃全额（试水实测见 §八.3：azure 悬崖 0% / auric 平推 100%）。
  - ❌ 方案 2：把品质阶梯改为「数值+百分比」混合（docs/65 §3.5 已论证动品质带代价过高，维持不做）。
  - ✅ **方案 3（小督修正③，照小尺 8b1f336 先例「直接量漂移本身」）**：从实测安全边际带
    **[2, 8] 反解威胁因子**，做成 `EXPECTED_GEAR_ANCHORS` 的**威胁侧孪生**——插值锚点表
    （平滑、非阶跃，随等级插值，不在品质边界跳变），乘进 `monsterAtk`。
    与 P0-2b（深度副本反标定）同批实施（批 2），两轴一起标定。
- **验收**：N1 硬门禁全绿：每 10 级段普通关安全边际 ∈ [2, 8] 且最大值/最小值 ≤ 2×；
  威胁因子表平滑（相邻锚点插值，不产生新阶跃）；同批通过 balance:equipment-dungeon 全部门禁。

### A2 · 战力面板对暴击定价错约 40 倍（实锤 B，docs/65 已登记）

- **证据**（本次实测，Lv70 剑姬满配）：+1 点暴击率（1%）的真实输出增量 ≈ **+56.8 攻击**；
  而战力面板：+1% 暴击 = **+3 CP**，+56.8 攻击 = **+119 CP**。
  **暴击在面板里的定价只有它真实价值的约 1/40。**
- **根因**：`CP_WEIGHTS.critRate = 250` 是**等级无关的线性价**，而暴击的真实价值
  ∝ 攻击 × (0.5 + 暴伤/100)，随等级和装备膨胀。同理 `critDmg`、`spd` 也有此病。
- **手册依据**：§一.2（青木公：每个属性对 EHP/EDPS 的**导数为常数**，
  价值线性稳定，消灭「越堆越赚」的边际效应）——当前 crit 的 CP 导数是常数，
  但**它对应的真实 EDPS 导数是随等级涨的**，两者脱钩。
- **影响**：高暴击职业（喵喵基础暴击 10 = 剑姬 2 倍）真实强度被系统性低估。
  四职业同装备 Lv70 实测 CP/DPS：剑姬 6.60、魔女 6.21、灵巫 6.49、**喵喵 6.15**——
  面板最低估的就是喵喵。所有读 CP 的界面（推荐战力、章节门槛、榜单上界）都会误导。
- **处置（已拍板：按推荐 = 方案 1，定价形态按小督小项修正）**：
  - 方案 1：**重定价 CP 权重**。⚠ 定价形态不是「等级系数」——暴击真值 ∝ 攻击 × (0.5 + 暴伤/100)，
    是**构建耦合**不是等级耦合（小督小项：否则 N2 对非典型构建过不了）。正解：
    **crit/spd 权重从玩家自身攻击派生（乘法形）**，即权重 = f(玩家当前 atk) 而非 f(等级)；
    全量重标推荐线、门槛、榜单上界（批 3）。
  - 方案 2（真实 DPS × EHP 投影）：手册推荐方向，标尺整体重构，列为中长期。
  - P0-4 配套（修正⑤）：服务端 profiles 存量 combat_power 回填方案（或 CP 版本戳列）、
    `combatPowerBound` 同批重标、发版公告措辞——避免榜单新旧混排数周。
- **验收**：新增门禁「CP 对单属性的导数 ∝ 真实 DPS 导数」：全等级段、四职业，
  任一属性每单位增量在面板与真实输出中的相对占比偏差 ≤ 20%。

### A3 · typicalQualityAt 语义错位：口径不是「可得性」而是「典型持有」（docs/72 第 1 步结论，按修正②返工）

- **证据**（本次逐件核对 `EQUIPMENT` 全部武器）：
  - 口径：fine 15~24 / rare 25~39 / epic 40~64 / legendary 65~89
  - 实际掉落：**epic 在 Lv20**（r2）、**legendary 在 Lv52**（r5）/Lv56（副本 auric）、
    **mythic 在 Lv81**（副本 crimson）、r7 的 legendary 却要到 **Lv75** 才掉
  - 即：口径在 Lv20~51 之间**系统性低估**一档以上，在 Lv65~74 又**高估**（r7 的传说在 75 才出现）
- **根因**：品质阈值（15/25/40/65/90/110）是「满级 120、每档 15~25 级」时代的拍脑袋值，
  而区域实际品质带是「每区 3 档、约 10~13 级一换」，两者从未对齐过；
  副本档位（16/31/56/81）又往里面掺了第三套节奏。
- **影响**：`expectedBuildCp`（全仓唯一权威口径）在大量等级段给出错误答案 →
  推荐战力失真（docs/72 深度 d3 最难、d4/d5 反而变简单的「非单调悬崖」就是它造成的）。
- **处置（已拍板：按推荐 = 小督修正②返工，两个动作一起做）**：
  1. **语义纠正：typicalQualityAt 回到「典型持有」口径**（中位数玩家身上穿的，原阈值
     「模拟器 typicalQuality 分档中值」即持有口径，保留）。「首次可得」不是典型——
     首次可得会高估真实玩家（本版快照实证：入场模型战力凭空 ×1.62~1.64，
     violet/auric d4/d5 全 100%，门槛会反向对真实玩家过难）。
  2. **`expectedBuildCp` 放弃解析式（L^1.35 × QUALITY_MUL）**：改为从真实装备定义表
     **选装计算**——与副本 `blankDefinitionId` 同一选择函数族，把选择函数提升为公共纯函数
     （主线推荐战力与副本入场模型同一条链，量化误差自动吸收，docs/71 §六.3 小尺先例）。
  3. `qualitySchedule.ts` 单源表保留，但**降级为展示/推导辅助**：它仍产出
     `QUALITY_FIRST_AVAILABLE_LEVEL`（首次可得），供 N3 上界与文案展示使用，
     不再驱动持有口径。
- **验收**：N3 门禁改**双边**：`typicalQualityAt(level)` ≤ 首次可得（上界，不许宣称拿不到的品质）
  且 ≥ sim 30 天中位持有（下界，不许低估玩家实际穿的）。返工后重跑深度副本平衡，
  以实测为准评估 P0-2b 剩余工作量（violet/auric d4/d5 全 100% 应随持有口径回落）。

### A4 · 珍品商店装备超前品质阶梯 5~7 档（新发现，需决策）

- **证据**（本次实测 `eq_shop_*`）：珍品商店在售 **legendary@Lv16（月糖系列）、mythic@Lv20（夜蔷薇系列）**，
  而口径说 legendary 从 65、mythic 从 90 才开始。价格虽贵（docs/65 §五确认买得起且有用 59 关），
  但它让「买了红装的玩家」在 Lv20~64 期间的战力远超 `expectedBuildCp`。
- **性质**：这是**刻意设计的金币出口**（docs/65 §五论证定价健康），不是 bug。
  但它与「单一权威口径」冲突：买了的人超出标尺、没买的人对标尺 —— 章节门槛和推荐战力
  对这两类人必然有一方错。
- **手册依据**：§七.5（新增货币先画收支环；珍品是金币的「高价值出口」，本身合理）。
- **处置（已拍板：克劳德按推荐 = a + c）**：
  - a) 保持现状，把「珍品超前的部分」显式记入 `KNOWN_RESIDUALS`，并在文案上写明「超越当前区域掉落的过渡装」；
  - b) 把月糖/夜蔷薇的品质下调到 epic（与 berry-cream 同档），价格同步降——放弃「提前穿高品质」的爽点；
  - c) 保留品质，但把**门槛/推荐判定改为「吃珍品后按实际装备快照算」**（服务端已有 sync-profile 算力，
    技术上可行，改动集中在榜单与副本门槛）。
  - ✅ **a + c**：不砍爽点，让读 CP 的地方能识别「珍品持有者」。
- **验收**：无硬门禁；以 docs/72 §5.5 同款「具名豁免 + 自清扫」登记，上线后按持有率采样。

### A5 · CP 对防御/生命/闪避的定价也需复核（手册 §一.2 的完整版）

- **证据**：`def` 价 3.0/点、`hp` 价 0.15/点、`eva` 价 1.2/点 均为**线性固定价**。
  但防御的 EHP 价值 = 1/(1 - def/(def+C))，是**超线性**的（手册 §一.2 明说
  x/(x+A) 的唯一理由是 EHP 线性——前提是 C 随等级走，当前 C = K_DEF×等级 已满足）。
  真正的问题在 `eva`：命中公式 clamp(0.75 + (acc-eva)/800, 0.55, 1.0) 有上下限，
  闪避超过收益饱和点后**每点闪避的真实价值骤降**，固定 1.2 CP/点必然错价。
- **影响**：闪避堆叠的收益在面板上被高估 → 高闪避职业（灵巫、喵喵）面板虚高。
- **处置**：纳入 A2 的「CP 导数恒定性」门禁一并复核，不单独开线。
- **验收**：同 A2。

## 三、成长曲线问题（B 类）

### B1 · r5 成长凹陷：40~52 级战力只涨 1.41 倍（docs/65 §3，已登记）

- **证据**：本次增速对比实读 Lv40→50 玩家倍率 **1.334×**（邻区 1.7~2.2×）；
  epic 品质带独占 Lv40~64 共 25 级 ≈ 20 天，r5 整段落在平台上。
  满绯焰套只补 +2.7%（概率触发不进面板），玩家看到的是**面板 20 天不动**。
- **处置（docs/65 已定倾向 B + C，本次支持）**：
  - B：把 Lv45 的技能倍率跃迁（1.7→2.0）在 UI 明示（改表现不改数值）；
  - C：把「集齐绯焰套」做成 r5 的显式主线目标（内容侧）。
  - 不动品质带（docs/65 §3.5 已论证动它代价过高）。
- **验收**：无硬门禁；以「r5 段面板可见成长来源 ≥ 2 条」为完成判据。

### B2 · 品质跃迁「过山车」：10 级增幅在 1.19× 与 1.94× 之间交替（新量化）

- **证据**（本次 `npm run sim` 增速对比实读，满配战力每 10 级倍率）：
  Lv50→60 = 1.268 → Lv60→70 = **1.941** → Lv70→80 = **1.194** → Lv80→90 = **1.858** →
  Lv90→100 = **1.151** → Lv100→110 = **1.874** → Lv110→120 = **1.124**。
  玩家每隔 10 级经历「一次大跳 + 一次几乎不动」，且大跳都发生在品质跃迁点。
- **根因**：品质乘法阶梯（×1.5/×2.3/×3.6/×5.8/×9.2/×15）叠加在等级曲线上，
  品质跳档把 10 级的成长一次性吃光（手册 §二：经验/等级曲线应平滑，品质是离散奖励，
  两者该解耦）。
- **影响**：体感「拿到新品质猛一下，然后 9 级没感觉」——与 B1 是同一病根的两种表现
  （平台 + 悬崖）。
- **处置（已拍板：克劳德按推荐 = b + c 先落地，a 列中长期）**：
  - a) 品质档内拉平：把 `QUALITY_MUL` 的乘法改为「档内随等级线性过渡」的形态
    （品质决定上限，等级决定到达率）——最符合手册 §二，但改动面大；

## 四、战斗与职业问题（C 类）

### C1 · PvP 跨职业胜率严重失衡（新发现，当前无任何门禁）

- **证据**（本次 `npm run sim` PvP 矩阵实读，Lv60 同战力）：
  - 剑姬 vs 魔女 **78%**、剑姬 vs 喵喵 **78%**、魔女 vs 灵巫 **73%**
  - 喵喵 vs 剑姬 **仅 18%**（几乎被碾压）
  - Lv100 收敛后剑姬 vs 魔女仍 **71%**
  - 现有门禁只有「镜像 45~55%」——**镜像局永远 50%，交叉局再歪也全绿**
- **根因**：PvP 直接复用 PVE 平衡后的职业数值（`CLASS_ATK_MUL` 把四职业挂机效率
  拉平到 ±2%），但手册 §一.6 明确：**PVE 效率与 PVP 强度必须分开记账**。
  剑姬高血高防在 30 回合制 PvP 里等于「肉 + 输出」，而喵喵的高攻速/暴击优势
  被闪避收益饱和与低血防吃掉。
- **影响**：竞技场候选对手推荐（胜率预估）失真，玩家很快学会「只挑喵喵打」，
  喵喵玩家竞技场体验被摧毁。
- **处置（已拍板：克劳德按推荐，设计意图 = 无显式职业克制、纯靠数值对等）**：
  1. 先加门禁：**跨职业交叉胜率 ∈ [35%, 65%]**（全等级段、全职业对），红了才开始调；
  2. 调法优先级：PvP 专属数值（如 PvP 模式给低血职业承伤修正）> 调 CLASS_ATK_MUL >
     动基础属性 —— 尽量不动 PVE 平衡（已按推荐定为第 1 优先）；
  3. ❌ 显式克制表方案关闭（不引入石头剪刀布）；四职业在 PvP 里靠数值对等，
     反制关系由玩家配装/操作产生，不由职业克制表产生。
- **验收**：N4 交叉胜率门禁全绿（Lv60/Lv100 全职业对 ∈ [35%, 65%]）；同战力下无职业对
  呈「可感知但不碾压」的稳定胜负结构（即没有固定被吃的一对）。

### C2 · 灵巫在 divine 段的职业词条极值垫底，与 PvP 弱势共振（新发现）

- **证据**（本次 sim「职业词条可达输出极值」实读）：
  - Lv50 epic：灵巫 0.2718 **最高**；Lv110/120 divine：灵巫 **0.2288 / 0.1759 最低**
    （其余三职业 0.24~0.31），最大偏离 17.16%（仍在 ±20% 门禁内，但恒定垫底）。
  - 与 C1 的灵巫 PvP 弱势（vs 剑姬 32%、vs 魔女 35%）方向一致。
- **根因**：灵巫的输出词条只有 `sha_spirit`（灵击，数值型攻击）一条，divine 段
  装备基准值（L^1.35）进入平坦区后，数值型词条的边际收益被百分比型词条（wit_elem 等）甩开。
- **处置**：纳入 C1 门禁后按结果调（给灵巫补一条百分比输出词条，或在 divine 段
  重标 `sha_spirit` 系数）；**先有门禁再调**，不凭手感。
- **验收**：职业词条极值门禁从「≤20%」收紧到「≤15%」且不允许固定职业垫底超过 2 个等级段。

### C3 · 技能系统未完成：旧三职业各 3 个技能（目标 14），挂机仍用占位倍率（M3-3/4/5）

  - auric d5 胜率 22.2%/9.2%/25.8%/9.1% → **100%**
  - 入场模型战力：violet 7752~8822 → 12697~15914（约 **1.64×**）；auric 24795~31179 → 38617~50199（约 **1.62×**）
  - 装备选择（`blankDefinitionId` 实测）：violet Lv31 从 `eq_r3_*_rare(Lv28)` → `eq_r3_*_epic(Lv30)`；
    auric Lv56 从 `eq_r5_*_epic(Lv50)` → `eq_r5_*_legendary(Lv52)`
- **根因**：A3 把 `typicalQualityAt` 从「规划带」改为「真实首次可得」——epic@20、legendary@50 都比
  旧阈值（epic@40、legendary@65）早，于是 violet/auric 档位入口的入场模型装备品质升一档、战力抬约 1.6×；
  深度怪物标定（`DEPTH_ENCOUNTER_BASE` / `DEPTH_ATK_TARGET`）是**按旧玩家模型标定**的，没有跟着改，
  于是「三走一试一挣」（d1~d3 可过 / d4 五五开 / d5 要真投入）整条带被击穿成「全 100%」。
- **性质**：这是 A3 正确口径修正的**必然联动**，不是调参错误；HEAD 基线全绿、当前版本 20 个红格全部由
  玩家侧变强引起（怪物一行未动，`depthScaledMonster` 无改动）。
- **为什么现在不做**：反标定的对象（怪物攻击/血量）正是 A1 要动的同一批旋钮。A1 未落地前反标定，
  等 A1 上马又会被推翻——等于在歪标尺上调数（§九铁律）。**先设计反标定方案，与 A1 同批实施。**
- **方案设计要求**：吸取 `TIER_ENCOUNTER_SCALE` 逐档手填的教训（docs/66 §3.2），反标定必须
  **从「三走一试一挣」设计带反推**：以入场模型（锚定 d1 标称等级 + 时代装备）为基准，反解
  `DEPTH_ENCOUNTER_BASE.hp/atk` 与 `DEPTH_ATK_TARGET`，不允许给单档塞手填系数。
- **期间纪律**：`DEPTH_GATES_CALIBRATED=true` 保持硬拦、`KNOWN_RESIDUALS` 不新增豁免——红是真相，
  掩盖它只会让后续调参失去反馈。同时 `equipmentDungeonDepth.spec.ts` 哨兵②（威胁轴漂移仍存在）
  保持绿；实现 A1 + 反标定后按 docs/66 契约回改硬拦并删哨兵。
- **附带清理**：`KNOWN_RESIDUALS` 里「auric d5 shaman 胜局均时 75.0s > 67.5s」已随本轮全部 100%
  失效（balance 脚本已打出「豁免已失效」），反标定收口时一并删除。
- **验收**：各档 d1~d5 胜率回到设计带（d1≥95% / d2≥90% / d3≥80% / d4∈[20%,90%] / d5≤35%），
  且哨兵②按 docs/66 契约完成「改回硬拦 + 删哨兵」闭环。

### P0-3 · A1 试水结论（2026-07-31，已回退）

- **实现过的方案**：`monsterAtk` 乘品质时代因子 `QUALITY_MUL[typicalQualityAt(level)]`（A1 候选方案 1）。
- **验证结果**：威胁轴旧口径读数落进 [2, 8]（各段 2.11~4.53，漂移 0.57×），N1 全绿；
  但**深度副本联动系统性失衡**（`npm run balance:equipment-dungeon` 实测）：
  - azure：d3+ 直接 0%（悬崖更陡）——`depthAtkFactor` 用 `monsterAtk(L_d)/monsterAtk(L_1)` 做归一，
    A1 因子让 `levelContribution` 从 1.6× 变成 2.4×，而 `DEPTH_ATK_TARGET` 没变，d3 攻击比失效；
  - auric：全线 100%（「三走一试一挣」彻底平推）——A1 抬攻后怪血不变，玩家 90 秒内杀得完。
- **结论**：A1 不是局部改动，会牵动深度副本的威胁平衡；深度设计刻意没有分档手调旋钮
  （TIER_ENCOUNTER_SCALE 教训），需要先设计档位相关的反标定方案（= P0-2b），**A1 与 P0-2b 必须同批实施**。
- **处置**：本轮已回退（`src/core/progression.ts` 恢复 HEAD，无残留）。下一位实现 A1 时，
  必须同步处理「深度反标定 + 带宽门禁改回硬拦 + 删哨兵②」三件套闭环。

## 十、给老板的人话总结

**现在游戏的问题一句话**：战力数字和「能不能打过」不完全对得上，而且越到后期越偏——
后期怪物打不死你（防御类装备显得没用）、喵喵职业面板被低估、竞技场里剑姬把喵喵打成 78:18。

**这次计划要做的**：
1. **修标尺**（最重要的第一步）：让「战力」这个数字诚实地等于「真实强弱」，
   再把关卡怪物、推荐战力、副本门槛全部对齐——以后改任何数值都有可靠的尺子。
2. **修成长节奏**：20 天面板不动的「平台期」和隔 10 级猛跳一下的「过山车」都来自
   同一个品质阶梯问题，用「品质阈值对齐真实掉落」顺带解决一大半。
3. **修竞技场公平**：先加一个「跨职业胜率 35%~65%」的检查，红了再调，绝不复刻
   「镜像全绿、交叉全歪」。
4. **补完技能与扫荡**：技能是最大的未完成养成线（旧三职业各只有 3 个技能）；
   扫荡实装后体力才有去处。

**需要你决定的 4 件事**：
- 珍品商店红装（Lv20 就能买神话级）：保留 + 让门槛识别它（推荐）/ 降品质 / 维持现状不登记
- 体力系统：实装扫荡并接上体力（推荐）/ 删掉 / 隐藏
- PvP 职业克制：要不要做显式职业克制，还是「无克制、纯靠数值对等」
- 品质跃迁的平滑：先做阈值对齐 + UI 高光（推荐）/ 直接重构装备品质公式（改动大、风险高）

**下一步**：你拍板上述 4 件事后，按 P0 → P1 → P2 → P3 顺序施工，每期以
`npm run verify` 全绿 + 新门禁 N1~N8 全绿为完成判据。
