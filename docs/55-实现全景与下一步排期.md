## 五、两个必须记住的技术约束

新接手的 AI 最容易踩这两条：

### 5.1 `src/core/` 必须环境无关

Edge Function 用 `npm run edge:build` 把 `src/core` 打包进 Deno 运行时复算伤害。
所以 core 里**不能出现** Vue、Pinia、存储、`document`、`canvas`、`window`。

> 本轮实例：头像压缩要用 canvas，因此放 `src/ui/imageResize.ts` 而不是 core。

### 5.2 服务端复算是排行榜的地基

客户端**只提交搭配快照，不提交伤害数字**。任何「为了方便先让客户端报成绩」
的改动都会让排行榜第一天被刷爆，属于不可接受的倒退。

## 六、本轮踩过的坑（写下来省下一次）

| 坑 | 现象 | 根因 |
|---|---|---|
| GitHub Secret 改了不生效 | 线上仍是旧值 | Secret **只在构建时注入**，改完必须重新部署 |
| 项目 URL 少一个字符 | 「网络未连接」 | ref 是 20 位，复制时漏了中间一个 `h`，DNS 里不存在 |
| Edge Function 部署失败 | `zod` 裸导入解析失败 | `deno.json` 在函数目录**上一层**，CLI 只上传函数目录内的文件 |
| 聊天室长消息丢正文 | 只剩标题 | `messageLines()` 只认 `- [20xx-` 开头的行，多行正文读不到（已修） |
| 验证长图读不了 | `400 Unsupported image` | 单边超 8000px 或长宽比超 1:8 会被视觉接口拒绝 |
| `seasons` 表没开 RLS | —（潜在） | Supabase 默认把 public schema 授权给 anon，**没开 RLS 等于完全敞开** |
