## 二、地基修正点（先裁定的三件事）

### 2.1 神话台阶（Lv90）落在区域 8 内部

- 事实：`typicalQualityAt`：<90 legendary、≥90 mythic、≥110 divine。
  区域 8 的 8-4（89–92）与 8-5（89–92）跨过 90。
- 风险：若 r8 装备主题只到 legendary，玩家在 8-4/8-5 的「典型持有」
  将停在神话门槛外，推荐战力与 G3 门禁会在区域内产生一次台阶跳变。
- **裁定建议（待数值线确认）**：r8 主题品质组 = `['epic', 'legendary', 'mythic']`，
  主题基准 Lv84（区域中段）；**Lv90 的典型持有从 8-4 起自然升为 mythic**，
  与 typicalQualityAt 台阶对齐，不另设区域内部补丁。

### 2.2 龙渊套锚定

- r5/r6/r7 模式：套等级 = 区域顶部附近（50/62/76），品质 = legendary。
- **裁定建议**：龙渊套 `REGION_8_SET_LEVEL = 90`、`REGION_8_SET_QUALITY = 'mythic'`
  ——首个神话套，锚在跃迁点上，与 2.1 同向；若数值线认为神话过早破节奏，
  备选 legendary（此时 2.1 的品质组降为 `['epic','legendary']`），二选一由数值线定。
- **前提不变**：套件只做称号/展示，**无战斗效果**（与血月套同规则；
  若圣遗物化先行落地，则按圣遗物化口径重定）。

### 2.3 docs/44 与旧表的处置

- docs/44 的 r8 数值写于旧节奏，**全部作废**：推荐战力、掉落率/保底、
  碎片成本一律以 r7 现行参数为模板按 78~92 段重推，不手填。
- 新增：**90+ 段的推荐战力推导必须过 G3 门禁**（0.80~1.80 带内），
  这是本次修订层比 docs/59 多的一道判据——因为 90 台阶是 r8 独有风险。

## 三、节奏与门禁

### 3.1 节奏系数

- 约束只有两条（docs/59 教训：不写天数目标）：
  1. `STAGE_PACING_FACTORS[8] > 440`（单调递增，表：1/45/90/110/200/340/440）。
  2. sim 健康门禁全绿（3.2），门禁是唯一裁判。
- **起点建议 560**（r5→r6→r7 增量 +140/+100，取 >440 的整百偏中间值），
  以 3.2 的读数定稿，**不许为了天数拍数**。
- 不动 BOSS/精英全局倍率。

### 3.2 加 r8 后 sim 必须保持全绿的门禁

| 门禁 | 加 r8 后的预期 |
|---|---|
| G1（D1 ≤ Lv24 / 60 关） | 不受影响，必须保持 |
| G2（不越软上限） | 软上限自动变 95，自动通过 |
| G3（战力÷推荐 0.80~1.80） | **78~92 段必须仍在带内，重点看 88~92 跨台阶段**——越界说明 2.1 的品质组或节奏配错 |
| G4 / G5（卡点与单关上限） | r8 BOSS 关自然形成 ~1 天卡点，G5 单关 ≤3 天必须保持 |
| 无经验断档 | 78~92 段每个未顶上限的天必须有升级 |
| R5/R6/R7 经济门禁 + **R8 新增** | 四个全绿 |
| 装备副本平衡门禁 | r8 涉及档位必须重跑 |
| 试炼/竞技场 | 五职业 78~92 段 KPS 偏离 ±20%（四层门禁沿用） |

### 3.3 内容规模（ROADMAP 定量）

5 章 × 6 关 = 30 关；怪物 **28 种**（含精英/BOSS）；装备 **40 件**（含龙渊套 8）；
掉落表 **5 张**；材料 5 种。与 r7 同构，只多不少的部分是 90 台阶的 mythic 档。
