## 二、地基修正点（先裁定的三件事）

### 2.1 神话台阶（Lv90）落在区域 8 内部

- 事实：`typicalQualityAt`：<90 legendary、≥90 mythic、≥110 divine。
  区域 8 只有 8-5（89–92）跨过 90（8-4 为 86–89，顶到 89 不跨）。
- 风险：若 r8 装备主题只到 legendary，玩家在 8-4/8-5 的「典型持有」
  将停在神话门槛外，推荐战力与 G3 门禁会在区域内产生一次台阶跳变。
- **裁定（数值线 2026-08-03 拍板，非可选）**：r8 主题品质组 =
  `['epic', 'legendary', 'mythic']`，主题基准 Lv84（区域中段）；N3 上界要求
  typical ≤ 首次可得，typical 在 Lv90 跳 mythic，所以 **mythic 首次可得必须 ≤90
  （8-5 中段 Lv90 起掉；2026-08-03 修正：原「8-5 首关 Lv89 起掉」作废——
  89 起掉会让推荐线在 89 跳约 ×2.5，双样本 G3 必挂；90 起掉与 typical 翻转同点，
  台阶对齐）**，8-4 保持 legendary；**Lv90 的典型持有自然升为 mythic**，
  与 typicalQualityAt 台阶对齐，不另设区域内部补丁。
- **90 台阶实测风险（2026-08-03 小衡公式直算）**：若 mythic 按解析曲线落地于
  8-5 首关（Lv89），推荐线 88→89 跳约 ×2.5（~188k→480k），刚到 8-5 的全传奇
  持有者 ÷ 推荐 ≈0.45~0.50，跌破 0.80 下限。处置（优先序）：
  ① mythic 首次可得移到 8-5 中段 Lv90（仍满足 typical ≤ 首次可得）；
  ② 或 mythic 定义按 ~0.7× 曲线下调。另 79~88 段 legendary 定义需把推荐线
  接回解析曲线（当前 defs/anal 0.72@89 漂移约 28%）。

### 2.2 龙渊套锚定

- r5/r6/r7 模式：套等级 = 区域顶部附近（50/62/76），品质 = legendary。
- **裁定（数值线 2026-08-03 拍板）**：龙渊套 `REGION_8_SET_LEVEL = 90`、
  `REGION_8_SET_QUALITY = 'mythic'` ——首个神话套，锚在跃迁点上，与 2.1 同向
  （套件等级=区域顶与 r5~r7 同模式：50/62/76 → 90；品质与主题组同向，
  避免散件/套件错位）。
- **效果档是待设计的新决策，不得沿用旧前提**：r5/r6/r7 套装均有真实
  2/4/6 件战斗加成（如血月套 2 件=攻 +10%、4 件=暴击 +8、6 件=技能倍率 +18%，
  仅 8 件档为称号 / 徽记纯外观）。龙渊套若**不做**套装加成，必须显式
  `cosmeticOnly`（docs/58 §四），并写明与 r5~r7 的差异；若做，则 2/4/6/8 件档
  效果必须写入本修订层并纳入 sim（90+ mythic 档的套装加成是全新平衡量）。
  装备本身的 mythic 属性照常计入 CP，90+ 推荐战力必须按含 mythic 典型持有推导。

### 2.3 docs/44 与旧表的处置

- docs/44 的 r8 数值写于旧节奏，**全部作废**：推荐战力、掉落率/保底、
  碎片成本一律以 r7 现行参数为模板按 78~92 段重推，不手填。
- 新增：**90+ 段的推荐战力推导必须过 G3 门禁**（0.80~1.80 带内），
  这是本次修订层比 docs/59 多的一道判据——因为 90 台阶是 r8 独有风险。
- ★ 小衡 16:34 补充的两道必补门禁（本文档 §3.2 已并入）：
**A) 90+ 公式级 G3（双样本，公式直算）**：88~92 段分别用
  （a）88~89 全 r8 legendary 持有（8-5 首关前，比值 ≈1.18）与
  （b）90+ 混合持有（按 8-5 首关掉率进度取 1~2 件 mythic 替代对应部位，
  比值应落 0.85~1.0），两者 ÷ 推荐 ∈ [0.80, 1.80]；原 rec/E 比值是恒等式
  （recommendCP ≡ 0.85 × expectedBuildCp）无判别力，废除。Lv90 翻转点本身的
  瞬态（90 刚够级、仍全 legendary ≈0.74）不算 G3 失败——它是设计内 N6 台阶
  瞬态，由台阶登记说明，不进带内判定。公式直算不依赖逐日曲线（60 天水平线
  只到 ~79 级，逐日曲线验不到 90+）。
  **B) N6 台阶登记**：90 mythic 跳档会改变 Lv80→90 与 Lv90→100 段倍率，
  r8 数据落地后必须贴 N6 段读数。

## 三、节奏与门禁

### 3.1 节奏系数

- 约束只有两条（docs/59 教训：不写天数目标）：
  1. `STAGE_PACING_FACTORS[8] > 440`（单调递增，表：1/45/90/110/200/340/440）。
  2. sim 健康门禁全绿（3.2），门禁是唯一裁判。
- **起点建议 560**（r5→r6→r7 增量 +140/+100，取 >440 的整百偏中间值），
  以 3.2 的读数定稿，**不许为了天数拍数**。
- 不动 BOSS/精英全局倍率。

### 3.2 加 r8 后 sim 必须保持全绿的门禁

| 门禁 | 加 r8 后的预期 |
|---|---|
| G1（D1 ≤ Lv24 / 60 关） | 不受影响，必须保持 |
| G2（不越软上限） | 软上限自动变 95，自动通过 |
| G3（战力÷推荐 0.80~1.80） | **78~92 段必须仍在带内，重点看 88~92 跨台阶段**——越界说明 2.1 的品质组或节奏配错 |
| G4 / G5（卡点与单关上限） | r8 BOSS 关自然形成 ~1 天卡点，G5 单关 ≤3 天必须保持 |
| 无经验断档 | 78~92 段每个未顶上限的天必须有升级 |
| R5/R6/R7 经济门禁 + **R8 新增** | 四个全绿 |
| 装备副本平衡门禁 | r8 涉及档位必须重跑 |
| 试炼/竞技场 | 五职业 78~92 段 KPS 偏离 ±20%（四层门禁沿用） |
| **90+ 公式级 G3（新增·必补·双样本）** | 88~89 全 legendary 持有与 90+ 混合持有分别 ÷推荐 ∈ [0.80,1.80]；Lv90 翻转瞬态（≈0.74）由 N6 台阶登记说明，不进带内判定（公式直算） |
| **N6 台阶登记（新增·必补）** | 90 mythic 跳档后贴 Lv80→90 与 Lv90→100 段 N6 读数（档内成长 ≥ 下限，台阶处正常跳升） |

### 3.3 内容规模（ROADMAP 定量）

5 章 × 6 关 = 30 关；怪物 **28 种**（含精英/BOSS）；装备 **40 件**（含龙渊套 8）；
掉落表 **15 张**（每章 × normal / elite / boss 由生成器产出，与 r3~r7 同口径）；
材料 5 种。与 r7 同构，只多不少的部分是 90 台阶的 mythic 档。

## 数值线裁定结论（2026-08-03 小衡拍板，均已采纳）

1. **r8 主题品质组 = `['epic','legendary','mythic']`（非可选）**：typical 在 Lv90
   跳 mythic，N3 上界要求 typical ≤ 首次可得 → mythic 首次可得必须 ≤90
   （8-5 中段 Lv90 起掉），8-4 保持 legendary。
2. **龙渊套 Lv90 / mythic（采纳）**：套件等级 = 区域顶（r5~r7 = 50/62/76 → r8 = 90）；
   品质与主题组同向；效果档按上文「待设计的新决策」执行。
3. **`STAGE_PACING_FACTORS[8]` 起点 560（同意，以 sim 读数定稿）**：单调 >440，
   门禁是唯一裁判，不许为天数拍数。
4. **两道必补门禁（§3.2 已并入）**：90+ 公式级 G3、N6 台阶登记。
