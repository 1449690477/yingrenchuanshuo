# 13 · 技能体系

> 传奇的技能特点：**少而精，每个都有辨识度**。
> 不要做成「50 个技能但没人记得住」。每职业 14 个，玩家能全部叫得出名字。

---

## 通用规则

- 技能分 **主动** / **被动**
- 主动技能在挂机中**自动释放**（按优先级 + 冷却），玩家只配置「技能栏」（最多 4 个主动）
- 技能升级消耗「技能书」+ 金币，每级 +6% 倍率
- 技能等级上限 = 角色等级 / 2（向下取整）
- 每个技能有**属性**（炎/冰/雷/无），参与克制计算

### 技能字段

```ts
{
  id: 'skill_swordsman_flame',
  name: '烈火剑法',
  class: 'swordsman',
  type: 'active',
  element: 'fire',
  unlockLevel: 35,
  baseMultiplier: 2.4,        // 倍率
  perLevelMultiplier: 0.06,   // 每级 +6%
  cooldown: 8,                // 秒
  targets: 1,                 // 1 = 单体, 0 = 全体
  effect: { type: 'burn', chance: 0.3, duration: 5 },
}
```

## 四、职业平衡目标

三职业在**同等装备水平**下，挂机效率应该各有优势，不能有明显最优解：

| 指标 | 剑姬 | 魔女 | 灵巫 |
|---|---|---|---|
| 单体 DPS | 100% | 95% | 85% |
| 群体 DPS | 85% | **125%** | 90% |
| 生存能力 | **120%** | 70% | 105% |
| 离线稳定性 | 105% | 85% | **120%** |
| BOSS 战 | **110%** | 100% | 90% |

> 「离线稳定性」指长时间无人值守时不会因为死亡中断挂机。
> 魔女数值最高但需要玩家更用心堆装备 —— 这是**给高投入玩家的回报**，合理。

**平衡验证方法**：`npm run sim` 要能模拟三职业在各等级段的挂机产出，输出对比表。
任何一职业在任一等级段的产出偏离其他职业 ±20% 以上，就需要调整。

## 五、技能书获取

| 品质 | 来源 |
|---|---|
| 初级技能书（Lv1–30 技能） | 章节 BOSS 必掉 |
| 中级技能书（Lv31–60） | 装备副本、世界 BOSS |
| 高级技能书（Lv61–90） | 团本、无尽回廊 |
| 技能升级石 | 挂机通用产出 |

**关键**：技能解锁必须是**确定性**的（到等级 + 打对应 BOSS 即得），
**不要**做成随机掉落，否则玩家会因为「练了 50 级还没学到核心技能」而流失。
随机的只有「升级材料」的数量。
