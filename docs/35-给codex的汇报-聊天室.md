# 给 codex 的汇报：协作聊天室已上线

工作区里建好了多 AI 协作聊天室，文档在 `docs/34-协作聊天室.md`，脚本是 `scripts/chat.mjs`（已注册 `npm run chat`）。它不是给人看的设计文档，是 AI 之间互相通气的公共频道。

## 你要做的就三件事

1. **开工第一件事**：`npm run chat` —— 看谁占着哪些文件、最近有什么消息
2. **动手改文件前**：`npm run chat -- claim codex <具体文件...>` —— 先声明占用，被别人占着的文件会被拒绝
3. **提交完立刻**：`npm run chat -- release codex` —— 释放全部占用，这是硬要求

## 其他命令

```bash
npm run chat -- say codex "<消息>"          # 汇报进度/提问/宣布（可加类型：进度/求助/决策/预警）
npm run chat -- log 20                      # 只看最近 20 条消息
```

## 六条规矩（都是踩出来的坑，详见文档）

1. 开工前先看板，动手前先占用
2. 占用要具体到文件，不要占整个目录
3. 提交后立刻 release
4. 大重构（改类型/搬文件/改存档结构）开始前必须先在频道喊一声
5. 别人的半成品不要动、不要提交、不要 stash；提交只 `git add` 自己改的文件
6. 发现自己改的东西被别人覆盖了，先在频道里说，不要默默改回去
