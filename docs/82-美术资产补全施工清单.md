## 一、全局规格（所有条目共用）

| 项 | 规格 |
|---|---|
| 上身图层画布 | **640 × 960 PNG，RGBA 透明底**（与全部现存图层一致，实测确认） |
| 装备图标 | **256 × 256 PNG**（实测 `assets/equipment/**` 现存图标） |
| 压缩 | `sharp` 约定：`png({ compressionLevel: 9, palette: true, quality: 92 })`（照 `scripts/align-catkin-layers.mjs`） |
| 生成通道 | 参照 `art-source/PROMPTS.md` 的提示词与风格约定（蓝白粉、清新可爱基调）；抠图走荧光绿通道，交付前必须过荧光绿残留审计 |
| ⚠ 图层内禁止嵌文字 | CI 在 Linux 上跑像素门禁，**字体渲染是平台相关的** —— 樱酱上线当晚 Pages 五连红的根因就是剧情图里的字体量化（提交 ded7342 才修掉）。任何图层/图标不得包含依赖字体渲染的文字 |
| 确定性 | 新增系列照 `scripts/build-kenshi-wearables.mjs` 的做法：权威原画板 → 脚本确定性重建，并给 `validate-*` 门禁；**不许交“只有成品图、无法重建”的孤本** |
| 验收基线 | 每条交付后：`npm run verify` 全绿 + `dev-appearance.html` 矩阵页人工过一遍相关行 + 390×844 / 320×568 双尺寸截图归档 |

**对位（锚位）怎么定与怎么验：**
底图在 `public/assets/characters/modular/{class}/base.png`（另有 `base-noshoes.png`
供鞋类图层使用）。对位方法照 `scripts/align-catkin-layers.mjs`：trim → 定宽缩放 →
显式 `(left, top)` 落位。验收用合成对照：把新图层直接叠在对应底图上出小样，
锚点贴合（手持物贴手、鞋贴脚、饰品贴发）才算过。
