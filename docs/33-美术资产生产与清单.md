# 33 · 美术资产生产与清单

> 所有 AI 生成素材都要走「生成 → 抠图 → 压缩 → 文件校验 → UI 接入 → 手机截图」，
> 不能只把图片丢进仓库，也不能让代码引用不存在的占位路径。

---

## 一、统一风格

- **气质**：清新、可爱、明亮日系；成年少女感，避免幼态化和性感化。
- **主色**：天蓝、白、樱粉；深蓝负责轮廓和可读性，少量金色做高光。
- **画法**：2D 日系手游立绘，清晰线稿和赛璐璐上色；手机小尺寸下仍要有明确剪影。
- **禁止**：水印、文字、品牌标志、写实照片质感、复杂灰雾、脏背景。

## 二、资产技术规格

| 类型 | 最终尺寸 | 格式 | 建议体积 | 用途 |
|---|---:|---|---:|---|
| 人物立绘 / 动作 | 640 × 960 | 透明 PNG | ≤ 550 KB | 创角、角色卡、战斗 |
| 角色纸娃娃层 | 640 × 960 | 透明 PNG | ≤ 300 KB | `base/body/head/shoes/weapon` 同画布叠加 |
| 技能大特效 | 512 × 512 | 透明 PNG | ≤ 250 KB | 战斗覆盖层 |
| 技能 / 装备 / 掉落图标 | 256 × 256 | 透明 PNG | ≤ 120 KB | 30–56 px UI 图标 |
| 怪物母版 | 512 / 768 | 透明 PNG | ≤ 500 KB | `art-source/monsters/`，不进入发布包 |
| 怪物运行时贴图 | 512 × 512 | 透明 WebP | ≤ 120 KB | 战斗区、图鉴；统一脚底锚点 |
| 区域地图 | 768 × 1024 | WebP | ≤ 450 KB | 竖屏关卡选择 |
| 章节战斗场景 | 1536 × 1024 | WebP | ≤ 520 KB | 3:2 横版战场，下半部留战斗地面 |
| 系统插画 | 512 × 512 | 透明 PNG | ≤ 320 KB | 强化、分解、扫荡、副本等功能入口与反馈 |
| PWA 品牌图标 | 192 / 512 | 不透明 PNG | ≤ 120 KB | 桌面安装、启动器、系统分享与 favicon |

## 三、绿幕生产流程

1. 透明主体用内置图片生成工具输出纯色 `#00ff00` 背景源图，主体里禁止出现绿色；全幅地图直接生成不透明场景，不走绿幕。
2. 源图临时放到 `tmp/imagegen/`，最终文件放到 `public/assets/` 对应目录。
3. 使用已安装的 `remove_chroma_key.py`，开启 `--soft-matte` 与 `--despill`。
4. 按上表缩小并压缩；透明主体母版移入 `art-source/`，发布用怪物贴图通过 `npm run monsters` 重建。
5. 检查必须满足：
   - RGBA 模式；
   - 四角 alpha 都为 0；
   - 主体 alpha 包围盒非空；
   - 无明显绿边、断肢、裁切、水印；
   - 对应 `src/data/` 配置测试确认文件真实存在。
6. 在 390 × 844 浏览器尺寸检查实际画面，并查看 warning / error 日志。

## 四、命名规则

```text
public/assets/characters/<class>-<theme>[-action].png
public/assets/characters/modular/<class>/<base-or-region-slot>.png
public/assets/characters/modular/shop/<theme>/<class>-<slot>.png
public/assets/effects/<class>-<skill>.png
public/assets/effects/basic/<class>-<attack>.png
public/assets/effects/boutique/<theme>-<class>.png
public/assets/icons/skills/<class>-<skill>.png
public/assets/equipment/<region>/<slot>.png
public/assets/equipment/shop/<theme>/<item>.png
public/assets/items/<item-id>.png
public/assets/shops/<shop-scene>.webp
art-source/monsters/<region>/<monster-id>.png
public/assets/monsters/<region>/<monster-id>.webp
public/assets/maps/<region-or-chapter>.webp
public/assets/battlefields/chapter-<chapter-id>.webp
```

品质不重复生成同一件装备图片；白、绿、蓝、紫等品质由 UI 边框和光效表达。
