# 冰雪 v2 母版 · 机械对位候选包（小尺 2026-08-03 验收报告）

**来源**：GPT 交付的 ice-snow-v2 重画母版（../ice-snow-v2/，其 README 自述
「未做逐件锚点校正，不能未验收上架」——诚实，且实测属实）。

**实测偏差（v2 原包 vs 现架对齐版，alpha 包围盒）**：武器五张严重错位
（Δ中心最大 333px、Δ尺寸 +300~530px，均为超尺寸展示件）；帽五张系统性
下移 48~60px；裙/鞋中心偏 ≤30px 但轮廓重画差异大。**结论：原包不可直接
替换上架，与其自述一致。**

**本目录 = 机械对位候选**：每件 v2 内容按 alpha 包围盒等比映射到现架同名
件的包围盒（裁切→等比缩放→中心落位）。回测残差：19/20 中心偏差 0px，
最大 24px（swordsman-weapon）。五职业武器叠底样张人工过目：全部落手位。

**尚未做、须由冰雪套负责人完成后才可替换上架**：
1. 逐件人工审美（机械对位保锚点不保构图取舍）；
2. `node scripts/validate-ice-snow-assets.mjs` 全绿（含樱酱无内置鞋合同、
   与旧主题 IoU 防伪装复制等门禁——报告数值会因换图而变，需重新裁定阈值内）；
3. 12 张 v2 图标 vs 现架 13 张的清点（数目不一致：候选包少 1，差异件待对表）；
4. 双尺寸实机截图 + docs/84 流程收口。

**替换方式**：逐件覆盖 public/assets/characters/modular/shop/ice-snow/ 同名
文件（本目录文件名与现架一一对应），不动注册代码。
