# 冰雪华年 body 母版重生成工单：从「衣服平铺」到「穿着立绘」

2026-08-04 晨，老板试穿实测定性：v2 的五张 body 母版是**衣服平铺图**
（假人台式、无手臂无姿态），穿上后角色「只剩一个头」。对照 v1（绯夜等）
的 body 层都是**人物穿着状态**的立绘——有手有姿态。这不是管线问题，
管线救不出母版里不存在的手臂；需要按下述工单重新生成五张 body。

## 生图通道现状（2026-08-04 06:0x 实测）

- codex imagegen：额度耗尽，**2026-08-08 19:10 恢复**
- OpenAI Images API：config.json 无 key（账号账单上限 0）
- 网页版 ChatGPT（老板本人会话）：可用 —— 上一批 v2 包就是这么来的

## 通用要求（五张一致）

- 单人、全身、正面站立、构图与 640×960 纸娃娃底模一致（头顶留出帽区，
  脚底贴近下缘）；竖版 1024×1536，之后由管线缩放对位
- **穿着状态**：人物穿着「冰晶华年公主裙」——象牙白裙身+冰蓝薄纱大氅+
  珍珠坠饰+小小中国结（沿用 docs/art/ice-snow-v2 现有裙子的设计元素）
- **双手双臂必须可见**（大氅前开，手自然下垂或轻提裙摆）；面部完整可见
- 纯绿 #00ff00 背景（走 remove_chroma_key 转 alpha）
- 不画武器、不画独立帽（帽/武器另有图层）；脚上画**素色内衬袜**即可，
  不画成品靴（靴是独立鞋层，防双鞋）

## 交付与接线

1. 生成五张 → 命名 `worn-body-{classId}.png` 放入本目录 `worn-source/`
2. 管线侧（找小尺或任一冰雪线同事）：绿幕转 alpha → 缩放对位 640×960 →
   替换 `art-source/shop/ice-snow/wearable-base/{classId}-body.png` →
   `node scripts/build-ice-snow-assets.mjs` → 门禁全绿 → 样张给老板过目
3. 注意：换成穿着立绘后，build 的贴头/垫脚工序与 validate 的
   头区/垫层豁免、裙宽探针需要按新母版重标（届时一并调整，工作量小）

## 为什么不能现在自动跑

见「生图通道现状」。老板若愿走网页版，把上面通用要求+职业特征拼进
提示词即可，五张分五次出图；回来喊管线侧接线，半小时内可上线。
