# 35 · 喵喵角色制作与管线

> 本文记录第四职业 `catkin`（展示名“喵喵”）的可复现美术、数据与接线边界。
> 原始参考来自棕白猫吉祥物：蓝色泪滴脸纹、圆润肉球、软萌但动作夸张。

## 一、角色设定

- **身份**：18 岁以上的成年猫灵少女，避免幼态角色歧义。
- **轮廓锚点**：焦糖棕短发、奶油色耳内与尾尖、蓝眼、双颊蓝色泪滴、粉色肉球、蓝晶爪。
- **职业定位**：高速连击、闪避反击、猫爪印记；血防偏低，单体与 BOSS 爆发较强。
- **稳定 ID**：代码和存档一律使用 `catkin`；“喵喵”只是可本地化的展示名。

## 二、动作模组

| 动作状态 | 用途 | 代表技能 |
|---|---|---|
| `idle` | 呼吸、耳朵与尾巴待机 | 常态 |
| `attack` | 基础肉球爪击 | 普攻 |
| `cast` | 抬爪聚能 | 毛球风暴 |
| `react` | 触摸回应 / 问候 | 角色互动 |
| `dash` | 前扑突进 | 追光飞扑、纸箱奇袭、月影猫步 |
| `flurry` | 高频左右乱抓 | 肉球三连、疯狂乱抓、百爪樱岚 |
| `spin` | 尾巴与身体回旋 | 尾巴横扫、九命回旋 |
| `counter` | 炸毛后反爪 | 炸毛反击 |
| `victory` | 收爪、尾巴上扬庆祝 | 庆祝互动 |

动作由 `CharacterAppearance.vue` 的状态类驱动，保持与原三职业一致的轻量 CSS 管线。
喵喵额外使用独立 `catkin-motion-fx` 层区分动作语言：普攻 / 乱抓是交错爪痕，突进是水平残影，
回旋 / 反击是圆弧冲击环，施法 / 胜利是键帽粒子，受击是粉色涟漪。战斗态另有缩放与安全边距，
保证 320 × 568 下猫耳、尾巴和晶爪不被 3:2 战场圆角裁掉。
技能视觉契约在 `skillVisuals.ts` 中指定动作、特效类型与多段命中时间；战斗层当前统一
保留每次技能演出 980ms，真实技能执行器接入后再由结算事件决定持续时长。

区域装备的数值与存档继续复用共享 `defId`，但武器的玩家可见名称、图标和
纸娃娃必须按职业解析。喵喵固定显示“爪 / 晶爪 / 巨爪”语义，禁止回落到
通用剑名或剑图；新增区域武器时必须同时登记五职业表现，并通过各职业武器锚点测试。
这里的五职业指剑姬、魔女、灵巫、喵喵、樱酱；不能因为本文是第四职业的历史管线，
就漏掉后来并入的第五职业 `kenshi`。

- `art-source/characters/modular/catkin/alpha-master/`：固定画布透明分层母版。
- `art-source/effects/catkin/`：技能与普攻透明母版。
- `art-source/shop/*/catkin-*-alpha.png`：精品武器与攻击特效母版。

所有位图先用 ImageGen 生成纯绿背景，再统一通过官方
`remove_chroma_key.py` 抠图；不接受把运行时 CSS 滤镜当成透明素材的兜底。

## 四、重建与验收

```bash
npm run assets:catkin
npm run verify
npm run sim
npm run build
```

`assets:catkin` 顺序执行立绘构建、纸娃娃对齐、精品资产构建、技能资产构建和质量审计。
当前审计覆盖 57 个运行时文件与 18 个透明母版，检查 RGBA、尺寸、体积、透明四角、
主体包围盒和荧光绿残留。纸箱套另由 `assets:catkin-cardboard` 精确验证 5 个运行时文件，
并可重复生成 `art-source/qa/catkin-cardboard-outfit.png` 与 1080 × 720 九动作极值图
`catkin-motion-extremes.png`。390 × 844 / 320 × 568 下的
创角、挂机战斗、养成纸娃娃、红色精品衣裙与头冠截图均归档在 `art-source/qa/`。

## 五、实现边界

喵喵首批上线时已完成：

- 创角、存档 v6、当时四职业的成长与模拟、纸娃娃、两区成长装、三套精品洛丽塔与猫猫专属纸箱键帽套。
- 14 个技能的强类型玩法数据、14 图标、10 个主动技能专属动作与大特效。
- 战斗表现节奏读取技能冷却长度和多段命中时序，养成页可预览各类动作；新关卡入场期间缓存首批真实拍并在 480ms 后播放，不再因游标重置丢失。纸箱套普通攻击使用自身命中特效，技能仍使用技能专属图。
- 游戏设置和系统 `prefers-reduced-motion` 均可关闭角色动作、震屏、环境粒子与命中特效，同时保留静态生命、伤害和掉落信息。
- 职业专属精品 BOSS 掉落按当前职业过滤。

以下三条是喵喵首批上线时的**历史缺口**，保留用于解释后续施工来源，不代表当前状态：

- M3-3 的原三职业当时为 9 / 42，尚缺 33 条才能补至 42 / 42。

- M3-5 当时缺技能升级存档、技能树和 4 主动栏配置。
