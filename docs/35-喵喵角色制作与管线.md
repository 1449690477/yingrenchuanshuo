# 35 · 喵喵角色制作与管线

> 本文记录第四职业 `catkin`（展示名“喵喵”）的可复现美术、数据与接线边界。
> 原始参考来自棕白猫吉祥物：蓝色泪滴脸纹、圆润肉球、软萌但动作夸张。

## 一、角色设定

- **身份**：18 岁以上的成年猫灵少女，避免幼态角色歧义。
- **轮廓锚点**：焦糖棕短发、奶油色耳内与尾尖、蓝眼、双颊蓝色泪滴、粉色肉球、蓝晶爪。
- **职业定位**：高速连击、闪避反击、猫爪印记；血防偏低，单体与 BOSS 爆发较强。
- **稳定 ID**：代码和存档一律使用 `catkin`；“喵喵”只是可本地化的展示名。

## 二、动作模组

| 动作状态 | 用途 | 代表技能 |
|---|---|---|
| `idle` | 呼吸、耳朵与尾巴待机 | 常态 |
| `attack` | 基础肉球爪击 | 普攻 |
| `cast` | 抬爪聚能 | 毛球风暴 |
| `react` | 触摸回应 / 问候 | 角色互动 |
| `dash` | 前扑突进 | 追光飞扑、纸箱奇袭、月影猫步 |
| `flurry` | 高频左右乱抓 | 肉球三连、疯狂乱抓、百爪樱岚 |
| `spin` | 尾巴与身体回旋 | 尾巴横扫、九命回旋 |
| `counter` | 炸毛后反爪 | 炸毛反击 |
| `victory` | 收爪、尾巴上扬庆祝 | 庆祝互动 |

动作由 `CharacterAppearance.vue` 的状态类驱动，保持与原三职业一致的轻量 CSS 管线。
技能视觉契约在 `skillVisuals.ts` 中指定动作、特效类型与多段命中时间；战斗层当前统一
保留每次技能演出 980ms，真实技能执行器接入后再由结算事件决定持续时长。

## 四、重建与验收

```bash
npm run assets:catkin
npm run verify
npm run sim
npm run build
```

`assets:catkin` 顺序执行立绘构建、纸娃娃对齐、精品资产构建、技能资产构建和质量审计。
当前审计覆盖 52 个运行时文件与 15 个透明特效母版，检查 RGBA、尺寸、体积、透明四角、
主体包围盒和荧光绿残留。额外人工复审覆盖全部 27 张 `catkin` 母版；390 × 844 下的
创角、挂机战斗、养成纸娃娃、红色精品衣裙与头冠截图均归档在 `art-source/qa/`。

## 五、实现边界

已完成：

- 创角、存档 v6、四职业成长与模拟、纸娃娃、两区成长装、三套精品换装。
- 14 个技能的强类型玩法数据、14 图标、10 个主动技能专属动作与大特效。
- 战斗表现节奏读取技能冷却长度和多段命中时序，养成页可预览各类动作；这层仅驱动视觉，不参与挂机收益结算。
- 职业专属精品 BOSS 掉落按当前职业过滤。

尚未冒充完成：

- M3-3 的原三职业当前为 9 / 42，仍需新增 33 条补至 42 / 42。
- M3-4 仍缺真实优先级 / 冷却调度、印记和状态生命周期、逐击命中 / 暴击 / 克制、
  无视防御、反击、必闪、召唤物与 seeded RNG 结算。
- M3-5 仍缺技能升级存档、技能树和 4 主动栏配置。

因此当前挂机收益仍用统一平均技能倍率。喵喵的印记、反击与条件技能已经有可执行的数据
契约和完整表现资源，但要等全职业共用的 M3-4 执行器接管后才算真正参与战斗结算。
