## M1 阶段的重要发现（必读）

M1-10 的数值校验**推翻了文档里三处原始设计**，全部记录在 `32-决策记录.md`：

| ADR | 问题 | 结论 |
|---|---|---|
| **ADR-005** | 原 `monsterHp = 200 × L^2.3` 导致 Lv50 杀一只怪要 **3800 秒**，游戏中期直接卡死 | 怪物曲线指数必须贴近装备的 `ITEM_POW(1.35)`，改为 `60 × L^1.45` |
| **ADR-006** | 暴击率被和攻击力一样乘装备基准值，Lv120 单件武器给 **115% 暴击率** | 百分比属性拆到 `SLOT_PCT_WEIGHTS`，只随品质缩放，不随等级 |
| **ADR-007** | 装备是职业通用的，把职业属性差异冲淡到失效，攻速最高的灵巫反而输出最高 | 新增 `CLASS_ATK_MUL` 百分比系数，作用于装备累加之后 |

**教训（写给后面每一个 AI）**：
数值设计里**单个指数没有意义，只有指数之间的差值有意义**。
想改 `MONSTER_HP_POW`，必须同时看 `ITEM_POW`。改完必须跑 `npm run sim`。
