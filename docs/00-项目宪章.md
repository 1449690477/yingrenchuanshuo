# 00 · 项目宪章

## 一句话定位

**手机竖屏上的二次元放置传奇** —— 挂着自动打，回来收装备；装备靠打不靠抽；强化会碎，但碎得起。

## 目标玩家

- 玩过传奇 / 传奇类页游手游，怀念「爆装备」快感，但没时间手动打的人
- 喜欢二次元角色和立绘，愿意为角色养成投入时间的人
- 通勤、午休、睡前碎片时间玩 5–15 分钟的人

## 核心循环

```
挂机自动战斗
   ↓  产出 经验 / 金币 / 装备 / 材料
角色变强（升级、穿装备、强化、学技能）
   ↓
推进更高关卡（怪更强、掉落更好）
   ↓
卡关 → 去副本刷定向材料 / 打 BOSS 抢装备 / 强化冲一把
   ↓
突破卡点，回到挂机
```

**每一次卡关都必须有明确的破局手段**，不能只有「再挂 3 天」。这是放置游戏留存的生死线。

## 日常循环（玩家每天做什么）

| 时段 | 行为 | 耗时 |
|---|---|---|
| 早上打开 | 领离线收益 → 扫荡 3 次 → 领日常 | 2 分钟 |
| 中午 | 打日常副本（今日材料本）→ 强化一波 | 5 分钟 |
| 晚上 | 世界 BOSS（定时）→ 公会团本 → 爬塔 | 10 分钟 |
| 睡前 | 切到当前能打的最高关卡挂机 | 30 秒 |

## 设计铁律

### 1. 装备靠打，不靠抽
这是传奇的灵魂，也是本项目和市面上抽卡放置游戏最大的区别。
**所有橙色及以上装备，必须有一条「打怪掉落」的获取路径。** 可以慢，不能没有。

### 2. 强化有碎率，但有保底
碎装备的心跳感是传奇的记忆点。但现代玩家承受不了纯随机：
- +9 以下永不损坏
- +10 起失败掉级，+13 起有碎率
- **连续失败累积幸运值，攒满必成**（保底）
- 保护符可防碎，从日常产出，不强制付费

### 3. 不做体力墙式的强制付费
挂机产出无限，体力只限制「扫荡」这种加速手段。
玩家花时间一定能变强，花钱只是快一点。

### 4. 每个系统都要能挂机化
新增任何玩法，先问一句：**「这个能自动做吗？」**
不能自动的，必须能一键 / 扫荡。手动操作只保留在「爽点」上（开箱、强化、抽词条）。

### 5. 数值可回溯
所有数值来自公式 + 配置表，不允许拍脑袋填。
调平衡时改的是曲线参数，不是散落各处的魔法数字。

## 明确不做的事（防止范围失控）

| 不做 | 原因 |
|---|---|
| 实时 PVP / 实时组队 | GitHub Pages 无服务器，做不了；异步替代方案已够用 |
| 大世界自由移动 | 竖屏挂机游戏不需要，且美术成本爆炸 |
| 8 方向行走精灵 | 竖版只需左右朝向，省 75% 美术量 |
| 语音 / 剧情动画 | 一年内不碰，优先级最低 |
| 自研引擎 / 自研 UI 框架 | 用成熟方案，把时间花在游戏本身 |

## 一年后的样子（验收标准）

- 手机浏览器打开，能装到桌面，离线可玩
- 9 大区域 / 45 章节 / 约 300 个关卡
- 3 职业各 14 个技能
- 8 装备部位 × 7 品质，约 400 件装备
- 6 类副本 + 世界 BOSS + 公会异步团本 + 无尽塔
- 完整养成线：等级 / 装备 / 强化 / 洗练 / 套装 / 宠物 / 时装 / 称号
- 有排行榜和公会（Supabase 后端）
- 一个新玩家能连续玩 30 天不断目标
