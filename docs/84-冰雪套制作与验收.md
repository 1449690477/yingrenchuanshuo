# 冰雪华年套制作与验收

> 状态：代码、系统链、五职业原创穿戴轮廓、五职业原创攻击特效、樱酱“无内置鞋”像素合同、58px 白底图标与双尺寸实穿均已通过独立复核；12 个 Edge Function 已全量 ACTIVE，现网下载核对、`ops:check` 与线上探针通过。当前等待最终提交与 Pages 发布。任一发布门禁失败时保持客户端不上线。

## 1. 玩家拿到什么

「冰雪华年新春礼装」是永久独立货架出售的当前顶段 T0 精品套，不做限时倒计时，也不以错过惩罚制造焦虑。五个职业各有自己的武器，其余七个部位为同主题装备：帽饰、连衣裙、项链、手镯、戒指、腰带和鞋履。每个职业完整购买价统一为 11.5 亿金币。

八件都是真实 `EquipmentInstance`，不是只换一张立绘；购买、背包、一键最优、锁定、强化、洗练、分解保护、三套装备预设与永久图鉴沿用现有同一条数据链。最终 BOSS `7-5` 也以每件 `0.001` 权重直接掉落同款，职业武器继续执行职业过滤，保留“装备靠打不靠抽”。

纸娃娃采用四层可见契约：身体、帽饰、鞋履、武器真实呈现；项链、手镯、戒指、腰带保持现有精品装备的 `slot-only` 规则，避免八张素材同时压脸或穿手，但仍参与属性、战力、养成和永久图鉴。樱酱的衣裙源是完整人物，因此仅她的冰雪 body 替换旧底模；该 body 在冰雪鞋的实际 Alpha 遮罩内必须与 `base-noshoes` 逐像素一致，独立 head / shoes / weapon 继续叠加，保证买到并穿上的三个部位都产生真实外观变化，同时不会双鞋。

## 2. 数值与经济口径

- 采用当前主线顶段 `Lv78 legendary` 裸装基准，不用 `divine` 硬抬品质；后者相对当前传奇约 2.59 倍，会直接破坏现有 TTK。
- 每件有 4 条按当前 `AFFIX_POOL` 与 `AFFIX_TIERS` 实际计算的固定 T5 中位词条，以及 3 条随机可洗槽；洗练只改变随机槽，不吞掉固定身份词条。
- T0 强度来自“顶段传奇裸值 + 真 T5 固定词条 + 3 个养成槽”，不额外伪造 `setId` 或套装倍率，避免与套装打造、图鉴和升阶语义重复叠乘。
- 五职业整套同价 11.5 亿：武器 2.1 亿、帽 1.3 亿、裙 1.9 亿、项链 1.4 亿、手镯 1.2 亿、戒指 1.6 亿、腰带 1.05 亿、鞋 0.95 亿。
- 货架在 `stage_7-5_6` 解锁；金币不足、关卡未解锁与售罄都先经过正式判据，失败不扣款。
- 当前已是顶段装备，升阶查询返回无更高路线；不会显示一个不存在的升阶目标。

## 3. 资产契约

| 类型 | 数量 | 运行时规格 |
|---|---:|---|
| 独立冰雪货架 | 1 | 960×640 WebP，3:2，不含文字 |
| 五职业穿戴层 | 20 | 5 职业 × 身体/头帽/鞋/武器，640×960 RGBA PNG |
| 装备图标 | 13 | 5 职业武器 + 7 通用部位 + 樱酱同源衣裙缩略图，256×256 RGBA PNG |
| 战斗主题光效 | 5 | 每职业 1 张，512×512 RGBA PNG |

穿戴层以已经实穿校准的同职业母版提供手、脸、腿和脚底定位，并把穿戴、图标和特效母版归档在本主题 `art-source` 内，不依赖仍会继续修订的其它精品运行资产。二轮审计发现最初的衣裙、鞋和武器仍与旧精品透明轮廓逐像素相同，因此新增雪绒披肩、双层透明侧裙、雪绒靴口与五职业冰晶武器结构，15 张运行层的归一 Alpha IoU 从 `1.000` 降至 `0.459–0.886`。穿戴层因共享人体锚点单独定标：旧层经过 10×7px 平移、97% 缩放或水平镜像后的伪装复制最低仍为 `0.966`，故以两组证据之间的 `0.95` 为拒绝线，并在每次 validator 中现场重造伪装件校准。樱酱 body 另有不能靠肉眼代替的无鞋合同：按冰雪鞋自身 `alpha > 20` 的 15,844 像素作真实遮罩，body 与 `base-noshoes` 的预乘色 MAE、Alpha MAE 都必须 `<= 0.1`；当前两项均为 `0.000`。新增轮廓仍必须通过双尺寸真实组件截图，不能穿脸、穿腿、离手或让鞋底漂移。首轮真实截图发现旧帽檐压眼后，帽区从 180px 纵向收至 100px，再以双尺寸截图复验脸部。13 枚图标统一增加 3px 霁蓝银灰外描边，并在白底合成后执行亮度与近白面积门禁；另以 `meanLum > 205 && meanChroma < 16 && darkRatio < 40%` 联合拒绝线捕捉在真实 58px 玻璃卡片上会消失的细武器。剑士冰剑和魔女冰杖使用更深的霁蓝核心，不靠 UI 背景兜底。

五张攻击特效采用独立绿幕原画与职业动作构图：剑士六棱雪刃斩、法师冰晶法阵、道士银铃雪符、喵喵冰爪猫印、樱酱横向居合雪线。二轮新增跨主题 Alpha 轮廓门禁：裁出包围盒并归一为 128×128 形状掩码，允许轻微平移且同时比较水平镜像。实测独立新图对旧主题最大 IoU 为 `0.589`；旧图经过 10×7px 平移、97% 缩放或水平镜像后的伪装复制最低仍为 `0.870`，所以取两组证据之间的 `0.82` 为拒绝线。达到阈值直接失败，并同时检查五张冰雪特效互相不共用高相似轮廓和绿幕污染。该门禁专门阻止“完整 PNG 哈希不同、实际只是换色或微调”的假原创。
