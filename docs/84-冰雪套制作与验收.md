# 冰雪华年套制作与验收

> 状态：代码、系统链、完整 verify 与独立视觉复核已通过；等待按“12 Edge → Pages”顺序完成生产发布。任一发布门禁失败时保持客户端不上线。

## 1. 玩家拿到什么

「冰雪华年新春礼装」是永久独立货架出售的当前顶段 T0 精品套，不做限时倒计时，也不以错过惩罚制造焦虑。五个职业各有自己的武器，其余七个部位为同主题装备：帽饰、连衣裙、项链、手镯、戒指、腰带和鞋履。每个职业完整购买价统一为 11.5 亿金币。

八件都是真实 `EquipmentInstance`，不是只换一张立绘；购买、背包、一键最优、锁定、强化、洗练、分解保护、三套装备预设与永久图鉴沿用现有同一条数据链。最终 BOSS `7-5` 也以每件 `0.001` 权重直接掉落同款，职业武器继续执行职业过滤，保留“装备靠打不靠抽”。

纸娃娃采用四层可见契约：身体、帽饰、鞋履、武器真实呈现；项链、手镯、戒指、腰带保持现有精品装备的 `slot-only` 规则，避免八张素材同时压脸或穿手，但仍参与属性、战力、养成和永久图鉴。樱酱的衣裙源是完整人物，因此仅她的冰雪 body 替换旧底模；独立 head / shoes / weapon 仍继续叠加，保证买到并穿上的三个部位都产生真实外观变化。

## 2. 数值与经济口径

- 采用当前主线顶段 `Lv78 legendary` 裸装基准，不用 `divine` 硬抬品质；后者相对当前传奇约 2.59 倍，会直接破坏现有 TTK。
- 每件有 4 条按当前 `AFFIX_POOL` 与 `AFFIX_TIERS` 实际计算的固定 T5 中位词条，以及 3 条随机可洗槽；洗练只改变随机槽，不吞掉固定身份词条。
- T0 强度来自“顶段传奇裸值 + 真 T5 固定词条 + 3 个养成槽”，不额外伪造 `setId` 或套装倍率，避免与套装打造、图鉴和升阶语义重复叠乘。
- 五职业整套同价 11.5 亿：武器 2.1 亿、帽 1.3 亿、裙 1.9 亿、项链 1.4 亿、手镯 1.2 亿、戒指 1.6 亿、腰带 1.05 亿、鞋 0.95 亿。
- 货架在 `stage_7-5_6` 解锁；金币不足、关卡未解锁与售罄都先经过正式判据，失败不扣款。
- 当前已是顶段装备，升阶查询返回无更高路线；不会显示一个不存在的升阶目标。
