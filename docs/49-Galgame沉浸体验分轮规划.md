# 49. Galgame 沉浸体验分轮规划（养成 + 奇遇）

> 目标：让玩家与角色相处时有充分的沉浸式体验——剧情文本、视觉表现、UI 交互全面向
> 正统 galgame 靠齐。本文由 kimi 起草（2026-07-29），作为分轮施工的总规划与认领依据。

## 0. 现状盘点（已核实）

**已有底子（好底子，别重做）：**
- 剧情弹窗：全屏场景舞台（模糊铺底 + contain 完整构图）、打字机、自动播放、
  回看面板、跳过、CG 白闪、语音挂载点、名牌/对白框玻璃质感。
- 好感内容：四角色各 12 幕（含 12 幕约会）、心情系统（calm/bright/moved/shy/playful）、
  记忆回响、约会日程板、礼物架、心虹珍藏、首批真实语音 5 句。
- 奇遇：8 条角色剧情弧（茜/穗两位 NPC）、逐句对白、立绘 cue、高潮 CG、
  奇遇手札、日常变体池、援助递进。
- 立绘通道：弹窗立绘 = 纸娃娃纸模（CharacterAppearance），mood 已映射到动作
  （idle/cast/victory）——但只在选项回应后变化。

**关键差距（与正统 galgame 相比）：**
1. 开场全程立绘一个动作到底（activeMood 开场恒为 calm），人物不会随台词变化。
2. 立绘没有表情差分——纸娃娃只有 3 个动作，脸永远一张。
3. 场景是死图：没有呼吸感（慢推近）、没有天气/粒子氛围（雨、萤火、樱吹雪）。
4. 文字没有演出：关键词没有变色/放大/震颤，情绪靠玩家脑补。
5. 奇遇视觉资产极薄：8 条弧只有 3 张场景、2 张 CG；茜/穗立绘复用率高。
6. 两个剧情舞台（好感弹窗 / 奇遇面板）是两套代码，演出能力不一致。
7. 看完就完了：没有 CG/场景回忆画廊，没有幕间日常闲聊，沉浸无沉淀。

**边界（不碰）：** 存档 schema 与 v10/v11 迁移（codex 领地）、洗练与数值门禁、
区域 3/4 内容线（codex-r34）、真实语音批量（老板指示暂缓）。

## R1 演出层：让现有内容「活」起来（低资产、高回报，约 1 轮）

不改一张图，纯代码演出升级：

1. **逐句心情 cue**：`EncounterLine` 增加可选 `mood` 字段；对白数据为关键句标注
   心情；弹窗 activeMood 改为「当前句 mood ?? 选项 mood ?? calm」。
   开场阶段人物随台词换动作，不再一镜到底。
   （好感 48 幕 + 约会 12 幕逐幕标注；奇遇 8 弧同步。）
2. **文字演出标记**：对白支持轻量标记语法（如 `《重点》` 变色、`！！` 震颤、
   `……` 减速打字），打字机逐字渲染时解释；reduced-motion 降级为纯变色。
3. **场景呼吸**：场景图 3% 幅度慢推近/拉远（Ken Burns，20s 循环，reduced-motion 关）；
   按场景 slug 配氛围粒子层（市集=光尘、湖畔=波光、雨夜=雨丝、萤火=流萤），
   复用 SakuraField 的粒子思路做成轻量 canvas 层。
4. **HUD 隐藏模式**：点击舞台空白处收起顶栏/对白框（再点恢复），方便玩家
   纯享 CG 与截图；ESC 也可恢复。
5. **奇遇舞台对齐**：奇遇面板复用好感弹窗的舞台层（模糊铺底 + contain + 呼吸 +
   粒子），消除两套演出差距；如结构允许抽出共用 `StoryStage` 组件。

验收：两档视口（390×844 / 320×568）逐角色逐状态走查；SSR 测试覆盖 mood 逐句
切换与标记渲染；reduced-motion 全部降级。

## R2 内容纵深：看完有沉淀（文本为主）

1. **幕间日常闲聊**：每角色按默契阶段解锁的可重复小对话池（每档 4-6 条），
   面板入口「和她聊聊」；不消耗每日互动、无奖励（纯陪伴），台词池稳定可复现。
2. **心之间信**：完成约会/关键幕后，她往心之手札留一封信（第一人称、回应玩家
   当时的选择）；手札新增「信件」页可反复读。信件不写数值、只是文本资产。
3. **回忆画廊**：面板新增画廊页——已解锁的场景与 CG 按幕排列，点开全屏纯享
   （复用 R1 的 HUD 隐藏模式），未解锁显示剪影与解锁条件。
4. **奇遇弧补全**：评估 8 条弧的情绪曲线，为缺「余韵」的弧补一段尾声对白；
   奇遇手札按角色分组并标记新信/新幕。

验收：文本全走既有 AffectionStoryDefinition/EncounterLine 管线；新增内容全部
有专项测试（数量、前置、回响 id 真实存在）。

## R3 视觉资产：表情差分与奇遇补图（重资产，Kimi 插件通道）

1. **表情差分（四主角）**：基于 modular 纸娃娃的 head 层做表情变体——
   每角色 5 个表情（微笑/害羞/认真/惊讶/难过）× 4 角色 = 20 张头部层。
   纸娃娃结构保证换装/姿势不变、只换脸，一致性由构造保证。
   弹窗按逐句 mood 切换表情层（R1 的 cue 此时驱动脸）。
2. **奇遇场景补齐**：8 条弧的关键场景 3:2 无人物图（预计 8-10 张）+
   每条弧一张纯物件高潮 CG（8 张），全部走「1536×1024 出图→裁角标→960×640
   webp→像素查重→联系表目检」管线。
3. **茜/穗立绘差分**：按情绪拍子补齐缺失立绘（评估后定量，预计每角色 4-6 张）。

验收：资产审计扩展覆盖 encounters 目录；contact sheet 人工目检；docs/47 式
管线留痕。

## R4 音频氛围（可选，需老板点头，与语音暂缓不冲突）

- 场景环境音循环（市集人声、雨声、夜晚虫鸣、湖面水声，sound-effects 通道，
  10-22s 循环），接入既有 sfx 开关与 voiceMuted 同管线；不做 BGM 曲。

## 轮次与协作约定

- 每轮 = 独立原子批次：精确 claim → 专项测试 → 全量 verify → 报备后提交 →
  五段交接。R1 不依赖任何资产，可立即开工。
- 估时：R1 一轮；R2 一轮；R3 资产量最大，拆两个子批（表情 / 奇遇）；
  R4 视老板意见。
- 提交红线复述：测试引用的实现必须同批入库（CI 教训）；共享索引期间
  add 后立即 commit。
