### 品质开放节奏（重要）

**不要提前放开高品质**，否则后面的区域没有东西可以给玩家：

```
r1–r2  稀有 rare        ← 教学期，白绿蓝
r3–r4  史诗 epic        ← 第一次「紫装」的兴奋
r5–r7  传说 legendary   ← 套装期，橙装＋套装效果
r8     神话 mythic      ← 红色品质，docs/11 明确标注在这里首次出现
r9     神话 / 棱彩      ← 无尽产出，长期目标
```

每个区域的装备生成仍走 `eq_{regionId}_{slot}_{quality}`，
只需在 `equipment.ts` 增加区域主题条目并设定品质上限。

## 六、区域 9 · 虚数回廊（Lv 92–120，无尽）

> **这是保证「一年后仍有内容可玩」的关键设计。**
> 优先级最低（M9 才做），但**架构要早点预留**。

### 6.1 结构

```
每 10 层为一个「界」
  界内 10 层：难度线性递增
  跨界时：难度阶跃（怪物属性重组、词缀变化）
每 5 层：一个 BOSS
每 25 层：一个「界主」
层数 = 排行榜指标
```

### 6.2 美术复用（重要，省成本）

**怪物由前 8 区素材重新配色 + 属性重组**，不出新图。
建议实现为：`monsterVisuals.ts` 增加 `tintHue` / `tintSaturation` 字段，
运行时用 CSS `filter: hue-rotate()` 着色。
**一张图能变出 6 种「虚数化」变体**，这是无尽区域可持续的前提。

场景同理：前 8 区的战斗背景加一层几何 / 数据化的叠加层即可。

### 6.3 产出

| id | 名称 | 档位 | 用途 |
|---|---|---|---|
| `coin_endless` | 无尽币 | currency | 无尽商店兑换（专属外观、觉醒材料） |
| `essence_awaken` | 觉醒精魄 | epic | 转职 / 觉醒系统消耗 |
| `shard_prismatic` | 棱彩碎片 | legendary | 合成棱彩品质装备（最高档） |

### 6.4 无尽层的数值

```
第 N 层怪物等级 = 92 + floor(N / 10) × 2      （每界 +2 级）
第 N 层怪物血量倍率 = 1 + (N % 10) × 0.18     （界内线性）
跨界血量阶跃 = × 1.35
界主额外 × 2.5
```

> ⚠ 无尽层**不给经验**（玩家已满级），只给上述三种产出与排名。
> **不设失败惩罚**：打不过就停在当前层，下次继续挑战，
> 不扣层数、不扣材料。掉层是典型的惩罚性机制。

## 七、强化材料曲线延伸

`enhanceProgression.ts` 目前只覆盖 1-1～2-5。**每新增一章都必须补一条**，
否则该章不产出强化石 / 玄铁矿，玩家推进到新区反而强化不动。

| 区域 | 建议全身 | 建议主养 | 本区产出重点 |
|---|---:|---:|---|
| r3 | +6 | +10 | 玄铁矿产量提升；最终 BOSS 稳定产幸运九 |
| r4 | +8 | +12 | 保护符从首通奖励转为 BOSS 常规低概率 |
| r5 | +9 | +13 | 强化石产量翻倍；幸运九进入精英掉落 |
| r6 | +10 | +14 | 玄铁矿大幅提升；保护符稳定产出 |
| r7 | +11 | +15 | 支撑首次冲 +15 的材料储备 |
| r8 | +12 | +15 | 红装强化成本更高，产出同步提升 |
| r9 | +13 | +15 | 无尽层稳定产出，作为长期补给 |

**每改一次这张表必须跑 `npm run sim`**，确认 30 天成长曲线仍在目标带内（M3-13 既有要求）。

## 十、每个区域的完工验收清单

新增任一区域后，以下全部要过：

| 检查项 | 目标 | 工具 |
|---|---|---|
| TTK（击杀单只小怪） | 5 ± 1.5 秒 | `npm run sim` |
| 每秒击杀 | 不撞 3.0 上限 | `npm run sim` |
| 四职业效率偏离 | ±20% 内 | `npm run sim` |
| 30 天成长曲线 | 无断档、无跳变 | `npm run sim` |
| 本区强化材料产出 vs 建议消耗 | **产出略高于消耗** | 手算 |
| 套装碎片获取周期 | 凑满一套 ≤ 2 周日常挂机 | 手算 |
| 移动端 390×844 / 320×568 | 无破图、无横向溢出 | 实机 |
| 资产审计 | 全部引用的图真实存在 | `npm run assets:*:check` |

> **「产出略高于消耗」是反复强调的一条**：略高 → 玩家有余裕、愿意尝试；
> 略低 → 卡住、焦虑，踩 [`40`](40-玩法设计透镜.md) 的红线。

## 十一、一句话总结

> **区域 5–7 是「有目标地刷」的三级台阶，区域 8 是投入的兑现（继承），
> 区域 9 是永不结束的那条线。**
> 三段的动机各不相同，不要用同一套「加数值」的思路做完。
