### 品质开放节奏（重要）

**不要提前放开高品质**，否则后面的区域没有东西可以给玩家：

```
r1     common / fine / rare
r2     fine / rare / epic
r3–r4  fine / rare / epic          ← 第一次「紫装」的兴奋
r5–r7  rare / epic / legendary     ← 套装期，橙装＋套装效果
r8     epic / legendary / mythic   ← 红色品质，docs/11 明确标注在这里首次出现
r9     神话 / 棱彩      ← 无尽产出，长期目标
```

每个普通区域的装备生成仍走 `eq_{regionId}_{slot}_{quality}`。品质上限不等于
只生成最高一档；每区必须显式列出三档，否则会出现 normal 权重存在、装备定义
不存在的空掉落。普通区域同部位跨品质共用一张基础图，品质由边框和特效表达。

> 前四个区域玩家是被推着走，从这里开始玩家要**自己定目标**。

### 2.1 章节配置

### 2.3 绯焰套（6 件）

对应传奇沃玛套。件数 6，装备等级 50。

**固定槽位**：`weapon / head / body / necklace / ring / bracelet`。腰带和鞋仍穿
R5 普通装备，不计入绯焰套件数；实现和资产清单都不得擅自扩成 8 件。

| 激活 | 效果 |
|---|---|
| 2 件 | 攻击力 +8% |
| 4 件 | 暴击率 +6%，炎属性伤害 +12% |
| **6 件** | **【绯焰】攻击时 15% 概率附加一次 120% 攻击力的炎爆伤害** |

**碎片路线已决策为 A**：全套只使用一种 `frag_crimson`；每消耗 **40 个**，
由玩家从上述六个部位中指定合成一件。不拆成部位碎片，**不做 3 换 1**。这条
R5 施工规则取代 `docs/12` 中“部位碎片可 3 换 1”的旧提案。

**武器元素已锁定**：

- R5 普通武器三档 `rare / epic / legendary` 全部为 `element: 'fire'`；
- 绯焰套武器同样为 `element: 'fire'`；
- 其余部位不写武器元素，不能从炎伤词条或套装名反推角色攻击元素。

**炎爆真实结算边界**：

- 每个真实攻击命中使用 seeded RNG 独立判定一次，触发后追加一段
  `120% atk` 的 `fire` 伤害；
- 追加伤害走统一属性克制、炎伤加成与目标防御计算；
- 炎爆自身不再独立暴击、不产生吸血、不再次触发炎爆，防止递归与双重收益；
- 挂机期望值与逐击战斗必须调用同一份纯函数或同源数学定义，UI 只消费结算事件
  播放火花、冲击环和飘字，不能用特效冒充伤害。

> ⚠ 当前 `core/equipmentSets.ts` 只支持基础 Stats 与平均技能倍率，并硬绑定
> 装备副本套装。绯焰的炎伤和 6 件炎爆都需要通用套装注册表、战斗触发纯函数
> 与专项测试；禁止只写文案或播放假炎爆特效。

**独立掉落与峰值规则**：

- `frag_crimson` 不进入 `ChapterSpec.materials`，而由独立套装经济表注入
  5-2「熔岩卫娘」、5-4「赤红神官」、5-5「熔心圣侍」的精英表，以及
  5-5「炎神官长·维斯塔」的真实 BOSS 表；
- 只向真实出现的怪物表注入，不能因为生成器预建了空 BOSS 表就让普通章节
  获得虚假的碎片来源；
- BOSS **不直接掉落绯焰整件**。R5 的单次掉落峰值由八部位普通
  `legendary` 装备承担，绯焰套只走通用碎片自选合成；
- 碎片权重、单次数量和保底次数，以及普通 `legendary` 的权重与保底，都由
  读取真实波次、击杀速度和离线时长的经济模拟生成，本文不手填概率。

经济模拟必须以一套所需的 **240 个**通用碎片为目标，输出 P50 / P90 / P95
成套天数、各来源贡献和保底触发占比；验收线为 P95 在 14 个有效日常挂机日内
凑齐六件。任何权重或保底调整都必须重跑模拟，超界时非 0 退出。

### 2.4 装备主题与首次出现

- **装备主题**：绯焰系（赤红 / 鎏金 / 火纹），品质上限 **legendary**
- **普通装备掉落峰值**：normal 只出 rare；elite 出 rare / epic；BOSS 出
  epic / legendary。具体权重和保底由真实经济模拟生成，不沿用当前全区域常量猜值。
- **首次出现**：套装系统、世界 BOSS（Lv45）、公会（Lv48）

### 5.3 装备主题与首次出现

- **装备主题**：龙渊系（暗金 / 龙鳞 / 魔城纹），品质上限 **mythic（红色）**
- **首次出现**：红色品质装备、**装备继承系统**

**装备继承**仍是提案，不是施工表。它与区域 1～4 的“同定义升级”不同，
必须另写纯计划函数，并先统一目标装备、旧装是否消耗、强化幸运、每级固定
增幅、洗练共鸣和词条类型的处理规则。下面仅保留原方向：

```
把旧装备的「强化等级 + 词条品阶」整体转移到同部位新装备上
消耗：龙渊核心 × 3 + 金币 × 新装备等级 × 800
旧装备消耗掉；词条类型重掷，但品阶保留
```

> 这条设计的意义：到区域 8 玩家已经洗了几百次词条，
> 如果换红装等于全部归零，投入被清空 ——
> 这正是《上瘾》里「投入」这一环最忌讳的事。
> **继承让长期投入可延续，是留住高等级玩家的关键。**

## 六、区域 9 · 虚数回廊（Lv 92–120，无尽）

> **这是保证「一年后仍有内容可玩」的关键设计。**
> 优先级最低（M9 才做），但**架构要早点预留**。

### 6.1 结构

```
每 10 层为一个「界」
  界内 10 层：难度线性递增
  跨界时：难度阶跃（怪物属性重组、词缀变化）
每 5 层：一个 BOSS
每 25 层：一个「界主」
层数 = 排行榜指标
```

### 6.2 美术复用（重要，省成本）

**怪物由前 8 区素材重新配色 + 属性重组**，不出新图。
建议实现为：`monsterVisuals.ts` 增加 `tintHue` / `tintSaturation` 字段，
运行时用 CSS `filter: hue-rotate()` 着色。
**一张图能变出 6 种「虚数化」变体**，这是无尽区域可持续的前提。

场景同理：前 8 区的战斗背景加一层几何 / 数据化的叠加层即可。

### 6.3 产出

| id | 名称 | 档位 | 用途 |
|---|---|---|---|
| `coin_endless` | 无尽币 | currency | 无尽商店兑换（专属外观、觉醒材料） |
| `essence_awaken` | 觉醒精魄 | epic | 转职 / 觉醒系统消耗 |
| `shard_prismatic` | 棱彩碎片 | legendary | 合成棱彩品质装备（最高档） |

### 6.4 无尽层的数值

原公式在第 10 → 11 层会把界内倍率从 2.62 重置到 1，再与“跨界 ×1.35”
产生互相矛盾的下降。无尽实现前必须先确定一个连续、严格递增的唯一公式，并
用第 9/10/11、24/25/26 层边界测试锁住；目前不在文档里伪造一个可执行公式。

> ⚠ 无尽层**不给经验**（玩家已满级），只给上述三种产出与排名。
> **不设失败惩罚**：打不过就停在当前层，下次继续挑战，
> 不扣层数、不扣材料。掉层是典型的惩罚性机制。
