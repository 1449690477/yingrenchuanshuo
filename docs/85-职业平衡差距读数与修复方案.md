**结论：不是「某职业整体弱」，而是差距按等级段震荡**——低段魔女快

关卡场景又反转。另外裸战力显示值低段差距 21%（剑姬 266 vs 魔女 220
@Lv10），玩家互相比数字时观感差。

## 二、根因

1. 挂机结算的技能倍率是 **M2 时代的级别查表、职业无关**
   （progression.ts 的 averageSkillMultiplier，注释自证「M3-4 会替换成
   玩家实际技能栏计算」——M3 清账后此处未接管）。职业差异全部来自
   CLASS_ATK_MUL 与基础属性曲线，各段的震荡就是这两条曲线与怪物曲线
   相位差的产物。
2. 灵巫的治疗/召唤价值在挂机模型里记为**零**（真实战斗里有值），
   她的 atk 乘子是围绕这个缺陷手调过的——所以贸然「按真实技能栏
   计算」会需要全职业重新定标，不是一个旋钮的事。

  历史档位表**不许动**——冻结历史表教训）。

  续航价值）。做完 P2 后 averageSkillMultiplier 退役。

## 五、根因修正（2026-08-04 午，小衡实测推翻本文 §二第 1 条）

小衡用技能栏对比实测证明：挂机 DPS 实际走 estimateRealSkillRotation
**真实轮转模拟**（召唤物攻击计值，src/core/combat.ts），不是本文 §二
所写的「级别查表职业无关」——我当时读到 store 的 averageSkillMultiplier
（那是旧表现层的承伤投影路径）就下了全称结论，错。真根因：

**灵巫默认技能栏（DEFAULT_ACTIVE_SKILL_ORDER）把 heal/all_spirits 两个
辅助技排进前 4，挤掉了 skeleton/soul_fire 输出位**。实测 Lv90 灵巫：
默认栏 KPS 0.1419，换召唤输出栏 0.1857（+31%，反超樱酱 0.181）。
读数口径差（我 34%/21% vs 小衡 40.5%/27.3%）：我取 npm run sim 的
固定档位表、他取 Lv90 直测 KPS，机制结论一致。

修复组合拳（小衡拟，等带队确认）：a) 灵巫默认栏改输出/召唤优先
（改变未自定义玩家的可见体验，需老板知悉）；b) 灵巫 atk base 10→12
修低段；c) 视 a+b 后中段读数决定是否微调召唤数值。P0 均衡带断言
与 P1 同批落地。本文 §三 的 P2（模型改造）撤销——模型没病。

## 六、(b) 取消记录（2026-08-04 午后，小Q 三裁①）

(b)「灵巫 atk base 10→12 修低段」**取消**。理由（小衡 13:01 核算、小Q
裁定）：atk base 进 cpInputFingerprint，改它必须升 CP_FORMULA_VERSION——
代价是全服玩家战力数字变动＋排行榜重排＋Edge 重部署，换来的只是
Lv10 段极差收窄 4.3 个百分点，不成比例。Lv10 段维持阶梯带 ≤45% 钉住，
等「低段技能池」专项（停车场项，老板过目后再议）。

教训一句话：**动基础属性前先查它在不在指纹里**——指纹字段的修改成本
是「全服可见数字变动」量级，不是数值本身的大小。
