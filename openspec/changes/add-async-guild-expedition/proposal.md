## Why

现有联机内容以排行榜和异步竞技为主，玩家能够比较成绩，却缺少共同推进目标和稳定的社交归属。公会首版需要证明“多人共同完成一件事”能够成立，同时不得中断挂机、强迫定时上线，或在服务端权威存档落地前发放可作弊转移的战力资源。

## What Changes

- 新增最多 20 人的异步公会：玩家可创建、浏览、加入和退出公会，会长可维护公告和移除成员。
- 新增按北京时间周一 04:00 重置的公会远征首领；成员使用当前角色搭配发起独立模拟，服务端复算贡献并累加到共享进度。
- 每名成员每天获得有限贡献次数，失败、断网或重复提交不得产生重复贡献；远征不改变挂机战斗、关卡、体力和本地掉落。
- 新增公会等级、周贡献与成员动态展示；首版仅提供荣誉与展示性成长，不发放装备、战力属性或可交易资源。
- Supabase 未配置或网络不可用时隐藏在线操作并明确降级，现有单机玩法继续正常运行。
- 在“更多”中增加符合蓝白粉竖屏风格的公会入口和独立页面。

## Capabilities

### New Capabilities

- `guild-membership`: 公会创建、浏览、加入、成员角色、公告、退出与移除规则，以及离线降级行为。
- `guild-expedition`: 每周异步首领、服务端复算贡献、每日次数、共享进度、周重置和展示性公会成长。

### Modified Capabilities

无。

## Impact

- 新增 Supabase 迁移、原子 RPC 与公会远征 Edge Function，并扩展共享 core 打包和服务端自检。
- 新增 `src/net/` 公会 IO、Pinia 公会状态、数据配置、纯函数远征结算、单元测试与公会视图。
- 调整“更多”入口和客户端路由；未配置 Supabase 时保持原有构建与单机流程。
- 更新系统清单、路线图、部署说明和进度快照；首版不修改本地存档结构与 `SAVE_VERSION`。
