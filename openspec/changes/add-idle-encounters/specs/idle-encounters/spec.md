## ADDED Requirements

### Requirement: 有效挂机产生待处理奇遇
系统 MUST 使用有效在线或离线挂机时间推进奇遇，并从当前地区可用配置中以可复现随机方式产生待处理奇遇。

#### Scenario: 在线挂机达到触发门槛
- **WHEN** 玩家在可挂机关卡累计的有效挂机时间达到当前奇遇门槛且队列未满
- **THEN** 系统将一个当前地区奇遇加入待处理队列

#### Scenario: 离线挂机达到触发门槛
- **WHEN** 离线收益结算包含足够的有效挂机时间且队列未满
- **THEN** 系统按同样规则生成奇遇，且不会改变离线收益内容

#### Scenario: 随机结果可复现
- **WHEN** 两份状态具有相同存档种子、生成序号、地区和挂机进度
- **THEN** 系统 MUST 产生相同的奇遇序列

### Requirement: 奇遇不得干扰挂机
系统 MUST 将奇遇作为挂机收益之外的独立待处理内容，不得暂停战斗、替换关卡目标或削减基础挂机结算。

#### Scenario: 奇遇进入队列
- **WHEN** 一个新奇遇产生
- **THEN** 战斗循环、关卡进度、经验、金币和原掉落继续按原规则结算

#### Scenario: 玩家打开奇遇面板
- **WHEN** 玩家主动打开或关闭奇遇面板
- **THEN** 挂机循环继续运行且当前关卡不发生切换

### Requirement: 待处理队列有明确上限
系统 MUST 最多保存 3 个待处理奇遇，队列满后只停止生成新奇遇。

#### Scenario: 队列已满
- **WHEN** 有效挂机继续推进但已有 3 个待处理奇遇
- **THEN** 系统不再添加奇遇且挂机收益继续正常结算

#### Scenario: 处理一个奇遇
- **WHEN** 玩家解决队列中的一个奇遇
- **THEN** 该奇遇从队列移除，后续有效挂机可以再次产生新奇遇

### Requirement: 玩家可选择材料交换结果
每个奇遇 MUST 提供两个配置化选项，并至少包含一个不消耗资源、可正常结束奇遇的选项。

#### Scenario: 资源充足时选择交换
- **WHEN** 玩家选择一个材料和金币均充足的选项
- **THEN** 系统原子扣除成本、发放奖励并移除该奇遇

#### Scenario: 资源不足时选择交换
- **WHEN** 玩家选择一个资源不足的选项
- **THEN** 系统不扣除任何资源、不发放奖励且保留该奇遇

#### Scenario: 玩家稍后处理
- **WHEN** 玩家关闭面板而不选择任何选项
- **THEN** 待处理奇遇及玩家资源保持不变

### Requirement: 奇遇状态持久化
系统 MUST 将奇遇进度、生成序号和待处理队列写入存档，并安全迁移旧版本存档。

#### Scenario: 从 v3 存档升级
- **WHEN** 游戏加载结构合法的 v3 存档
- **THEN** 系统迁移为空奇遇状态且保留所有旧资产和关卡进度

#### Scenario: 重开游戏
- **WHEN** 玩家在存在待处理奇遇时刷新或重新打开游戏
- **THEN** 待处理奇遇和已累计进度仍然存在

### Requirement: 奇遇入口遵循项目移动端风格
系统 MUST 在 390×844 竖屏挂机页提供轻量入口，并使用现有蓝白粉设计变量和系统图标。

#### Scenario: 没有待处理奇遇
- **WHEN** 奇遇队列为空
- **THEN** 挂机页不显示占用战斗空间的强制提示

#### Scenario: 存在待处理奇遇
- **WHEN** 奇遇队列至少有一个事件
- **THEN** 挂机页显示可点击的待处理数量，但不自动打开面板
