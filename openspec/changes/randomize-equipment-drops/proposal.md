## Why

现版已经让掉落装备拥有 80%～120% 的隐藏基础浮动和逐级强化成长，但界面直接展示“稳固胚 / 精工胚 / 奇迹胚”和百分比，玩家容易把掉落成色与强化锻造混为一谈；属性汇总又把基础、固定词条和随机词条叠在一起展示，难以判断换装差异。PR2 需要基于最新主分支重建，把既有装备随机、强化、背包与未来洗练/继承的边界统一起来。

## What Changes

- 在现版 `baseRollPermille` 字段上把新掉落分布调整为：65% 落在 80%～99.9%，33% 落在 100%～111.9%，2% 落在 112%～120%并自动锁定；不新增第二套成色字段，也不向玩家显示倍率或档位。
- 新增纯函数属性分解：强化后的隐藏浮动基础属性、固定词条、随机词条和总属性分别计算；强化只放大绝对基础属性。
- 为随机词条增加数据驱动的部位倾向，主词条更常见，但其他合法词条仍可出现。
- 背包排序、一键穿戴、装备比较继续统一使用当前角色上下文中的真实实例战力，并坚持按 UID 操作。
- 装备详情改为“基础属性 / 固定词条 / 随机词条 / 换装后总属性变化”，避免词条在汇总和词条区看起来重复计算。
- 强化台删除胚子档位与百分比；强化成功只展示本级实际成长。“稳固 / 精工 / 奇迹”仅描述本级锻造成长结果，“微光 / 辉光 / 星铸 / 樱华”继续表示累计强化外观阶段。
- 精品商店和精品 BOSS 同款继续使用固定 100% 模板、固定词条和自动锁定；高价值隐藏基础浮动仍可自动锁定，但不显示档位。
- 保持现有 v5 装备实例结构；本次不提升 `SAVE_VERSION`，现有 v5 存档可直接读取。

## Capabilities

### New Capabilities

- `randomized-equipment-instances`: 定义隐藏基础浮动、属性分解、部位词条倾向、强化/洗练/继承边界与确定性随机。
- `equipment-inventory-comparison`: 定义背包排序、UID 操作、装备详情分区、逐项换装差值和移动端展示。

### Modified Capabilities

无。

## Impact

- 核心纯函数：`src/core/equipment.ts` 及对应单元测试。
- 数据配置：`src/data/constants.ts` 的部位词条倾向。
- 装备生成与选择：`src/stores/game.ts`、`src/stores/inventory.ts` 的现有实例路径与回归测试。
- UI：`EquipDetail.vue`、`EnhancePanel.vue`、背包/养成页现有调用方。
- 文档：装备体系、ADR、ROADMAP、PROGRESS；存档仍为 v5，无迁移。
- 验证：OpenSpec strict、`npm run verify`、`npm run sim`、`npm run build` 与 390×844 流程验收。
