## ADDED Requirements

### Requirement: 已遇见角色拥有常驻旅途手札

系统 SHALL 从现有角色剧情配置、待处理奇遇和 v8 角色进度派生手札，只展示玩家已经遇见的角色、定性关系阶段和已经完成的幕次，不显示隐藏关系数值或未解锁剧情标题。

#### Scenario: 第一幕进入队列即视为遇见

- **WHEN** 某角色第一幕已经进入待处理队列但尚未完成
- **THEN** 旅途手札显示该角色和“初遇”阶段，但不把第一幕标记为已完成

#### Scenario: 完成幕次展示当时回答

- **WHEN** 玩家已完成某个一次性角色篇章并保存剧情回答
- **THEN** 手札显示该幕次和玩家当时选择的回答文案，不显示奖励或材料结果

#### Scenario: 未遇见角色不提前泄露

- **WHEN** 某角色既无完成进度也没有待处理剧情
- **THEN** 手札不显示该角色的姓名、幕次标题或剧情内容

### Requirement: 已完成剧情可以无奖励回顾

系统 SHALL 允许玩家从手札回顾已完成幕次的记忆回响、开场对白和所选回答回应；回顾 MUST 为只读操作，不修改资产、关系、完成记录、待处理队列或任何 RNG 状态。

#### Scenario: 回顾重建选择对应对白

- **WHEN** 玩家回顾一个已完成且记录了回答的篇章
- **THEN** 系统按当前选择历史重建该幕的记忆回响、开场对白和对应回应对白

#### Scenario: 反复回顾不重复发奖

- **WHEN** 玩家多次进入、跳过或退出同一篇章回顾
- **THEN** 存档资产、关系值、待处理队列、主 RNG 和奖励 RNG 均保持不变

### Requirement: 可重复日常拥有稳定对白变体

系统 SHALL 以存档种子、待处理 UID 和 encounter ID 可复现选择日常对白变体；同一 UID 在关闭、刷新和重新打开后 MUST 保持相同变体，关系阶段只能改变称呼或对白，不得改变成本、奖励和变体权重。

#### Scenario: 同一 UID 可复现

- **WHEN** 相同存档种子和待处理 UID 被多次解析
- **THEN** 系统返回相同的日常变体 ID、故事和对白

#### Scenario: 不同 UID 能产生变化

- **WHEN** 同一角色日常以多个不同 UID 产生
- **THEN** 固定测试样本中至少能够出现两个不同对白变体

#### Scenario: 关系阶段只影响文本

- **WHEN** 同一日常 UID 分别在两个关系阶段解析
- **THEN** 关系问候可以不同，但有效援助成本和奖励池保持一致

### Requirement: 日常援助跟随历史最高章节分档

系统 SHALL 从角色日常的有序援助档位中选择玩家历史已解锁的最高档；手动切回旧关不得降低档位，每个档位 MUST 只要求该章节或更早已有来源的材料，并保留免费结束选项。

#### Scenario: 早期玩家只看到早期材料

- **WHEN** 玩家只解锁第一档所需章节
- **THEN** UI 和结算都使用第一档材料成本与隐藏奖励池

#### Scenario: 推进后自动使用更高档

- **WHEN** 玩家历史最高章节满足后续援助档位
- **THEN** 下一次打开或结算该日常时使用满足条件的最后一个档位

#### Scenario: 回旧关不降低请求

- **WHEN** 玩家已解锁高档章节后手动挂机早期关卡
- **THEN** 日常仍使用历史最高解锁档位而不是当前关卡档位

#### Scenario: 材料不足保持原子性

- **WHEN** 玩家无法支付当前有效援助档位
- **THEN** 结算失败且资产、待处理奇遇和角色进度均保持不变

### Requirement: 同一角色不会重复占用待处理队列

系统 SHALL 在候选生成时排除当前队列中已经出现的角色，而普通非角色奇遇仍仅按 encounter ID 去重。

#### Scenario: 角色第一幕和日常不能同时入队

- **WHEN** 队列中已有某角色的任一篇章或日常
- **THEN** 该角色的其他候选均不会进入本轮可生成集合

#### Scenario: 处理后角色可以再次出现

- **WHEN** 该角色待处理奇遇已结算并从队列移除
- **THEN** 符合章节和篇章前置的角色事件可以再次进入候选池

### Requirement: 手札与动态日常保持非阻塞移动端体验

系统 SHALL 在挂机页提供与待处理奇遇分离的手札入口；手札和日常面板不得暂停挂机，并 MUST 在 390×844 与 320px 宽度下无横向滚动、关键按钮不小于 44px，减弱动效时关闭打字和漂移动画。

#### Scenario: 无待处理事件仍可打开手札

- **WHEN** 玩家至少遇见过一名角色但当前待处理队列为空
- **THEN** 挂机页仍显示旅途手札入口并允许回顾已完成剧情

#### Scenario: 关闭手札挂机继续

- **WHEN** 玩家打开、回顾并关闭旅途手札
- **THEN** 在线挂机计时和战斗结算持续推进
