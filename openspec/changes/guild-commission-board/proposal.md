# 公会协作大版本：团本、功勋、据点与收藏

## Why

现有公会已有成员、公告与每周异步远征，但玩家缺少每天可共同推进的目标，远征也缺少明确的长期去向。需要把它组织成不打断挂机的协作循环，同时遵守已合入的防篡改边界。

## What Changes

- 增加北京时间 04:00 刷新的三档远征建设委托；完成全会建设只提高展示声望与赛季据点。
- 将既有异步远征明确呈现为公会团本：仍由 Edge Function 从搭配快照复算伤害与评分，只累计当日最好成绩的差额。
- 新增仅存在 Supabase 的“公会功勋”：由已落库的团本新增贡献换算，带来源账和全局 request ID，不能由客户端填写。
- 新增赛季据点：每日建设完成、每周团本首次突破、成员的服务器功勋捐献共同推进阶段。
- 新增功勋收藏商店：固定服务器价格、每季一次、只记录外观/收藏，不向本地背包发装备、材料、金币或战力。
- 首页加入竖屏适配的建设、据点、捐献和收藏板；新后端未部署时柔和降级，不影响挂机或既有团本。

## Impact

- 新增 core/data 规则、网络契约、移动端组件、Supabase 迁移与 Edge Function 接线。
- 不改 SaveData，不提升存档版本。
- 部署需要先执行两份公会迁移，再运行 `npm run edge:build` 并部署 `guild-expedition`。
- 完整资产账本生产验收前，公会继续不发放本地可战斗资产。
