## Why

装备详情当前会继续打开洗练与跨区升阶弹窗，在装备副本奖励场景中最多形成三层窗口。手机端返回关系、焦点恢复和“我正在操作哪件装备”都因此变得不清晰，而洗练底层已经具备候选先落盘、结果后决定的安全流程，不需要再靠嵌套弹窗保护。

## What Changes

- 装备详情不再直接挂载洗练或跨区升阶面板，改为向页面请求打开对应操作台。
- 背包、养成和挂机页在关闭装备详情后，以单层窗口打开洗练坊或升阶台，并保留原装备 UID。
- 洗练坊支持按调用方指定的装备初始化；洗练前不增加确认弹窗，洗练后继续在同一操作台展示原词条与候选词条，由玩家选择保留或替换。
- 装备副本奖励仍可查看装备详情，但详情不再继续打开第三层洗练或升阶窗口。
- 删除只剩重复用途的旧装备详情洗练面板及其旧 UI 契约，保留核心洗练事务、候选持久化与 v12 存档结构。

## Capabilities

### New Capabilities

- `flat-equipment-actions`: 定义装备详情到洗练坊、升阶台的单层交接，以及副本奖励场景的层级边界。

### Modified Capabilities

无。

## Impact

- Vue 组件：`EquipDetail.vue`、`ReforgeStudio.vue`、背包/养成/挂机页与装备副本奖励组件。
- 删除重复的 `ReforgePanel.vue`，调整相关 UI 测试与父子事件契约。
- 不修改 `src/core/` 数值逻辑，不修改材料成本、随机、事务、存档版本或迁移。
